# SVOD name, ALNST and Tektur design system, drawn landing hero

**Decision (owner, 2026-10-13, tuned in the Design Grammars Landing Tuner; the DG Web UI design was accepted the same day):**

- **Name.** The product is **SVOD** in every language. It is a proper noun (`PRODUCT_NAME` in `ui-v2/src/i18n/index.js`, listed in `PROPER_NOUNS`, never passed through `t()`). Subtitle: EN «Encode Design Grammars», RU «Свод правил проекта». This amends the D-03 owner-fixed strings «Design Grammars.» / «Грамматика.» and «Encode your design intent.» / «Граф правил проекта.».
- **Two faces.** ALNST (Alien Stage, Latin + Cyrillic, one weight) for the main screen headings and the landing hero; Tektur (OFL, variable 400–900, Latin + Cyrillic subsets) for subheadings and all running text. Geist Mono stays only for code and data (Cypher, SWRL, ids). Michroma, Geist and Oswald are no longer referenced by the tokens; their files stay because DeGram evidence files hash them.
- **Headings.** Every heading is uppercase and carries no closing full stop (Projects, LLM model, Connectors, Reasoner, hero lines). Screen titles: ALNST 400, tracking 0.08em (`--tracking-screen-title`); subheadings: Tektur 600, 0.04em.
- **Landing type.** Hero: ALNST, 0.3em tracking, title `max(22px, 6vmin)`, subtitle `max(11px, 1.9vmin)`, 1.2em apart (was 0.55em). Menu items: Tektur 0.78vw, EN Regular 400 sentence case, RU Medium 500 capitals; the signed-in user's name is set exactly like the menu items. System line and Sign out: Tektur Medium 500.
- **Landing motion.** The ring is a crescent (closure 0.8, opening at −40°, tips thinning 0.93). The thinking sphere opens the sequence (0.2 × ring radius, 1.4 s hold), then the current leaves its rim and runs the crescent tip to tip. The hero lines are drawn along the lines of their glyphs: every stroke of every letter starts and ends together (0.95 s), the glyph dots pop in afterwards. Region figures sit one per row and rise word by word.

**Why:** the owner asked for a Russian-first identity with a short, meaningful name (SVOD = свод правил) and a cleaner, more distinctive futuristic look; Michroma had no Cyrillic, and the self-hosted Geist files carried Latin only, so Russian text fell back to the system face.

**How:**
- `AssembleText.jsx` draws a line as SVG: each glyph's outline is revealed through a mask of centre-line strokes.
- The centre lines and dots are generated by `ui-v2/scripts/gen_alnst_strokes.py`, which uses only the standard library: TTF parse, raster, Zhang-Suen skeleton, trace, prune. Its output is `alnstStrokes.js`. Re-run the script when the font or the character set changes.
- `landingEngine.js` carries the crescent mapping (`mapA`, `travelA`, `taperAt`) and the sphere.

**Open:** ALNST came with a copyright line only (Gerasimova's) and no licence. Confirm web-embedding rights before any public deployment or push of the font.
