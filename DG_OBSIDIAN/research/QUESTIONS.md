- Is it possible to make generative copilot system to augment an architect interactively expanding possible design solutions and validating it?
- Is it possible to make this system adaptable and ultimate for most of design scenarios and project requirements?
- How to define and enable metrics to map and benchmark suitable, high-performing design configurations?
- How to reuse data throughout the project development lifecycle?
- How to save design space options and retain reference between outputs and its inputs? Currently, once design is assessed and the optimal option is selected, output results get baked and parametric link with inputs gets lost. The solution may be to record the lists of generative solutions in project database.
- How to lightweight model representation during design recursive workflows meantime not losing the whole database?
- How to insure data sustainability during recursive workflows? 
	During design exploration process many vital data can be retrieved but when switching to new design option, the data assosiated with main concept retrieved from previous itteration can be lost. The solution may be the ability to synch this data to main design core database which retains stable and available at any design stage.
- How to record and trace design outputs automatically during development lifecycle? The solution may be to refer parametric elements to main design core database with corresponding nodes. So information is retrivable for all stakeholders at different design stages.
- How to use AI to request and analyze project data? The solution may be to structure data in GRaph database to make it accessible by AI.
