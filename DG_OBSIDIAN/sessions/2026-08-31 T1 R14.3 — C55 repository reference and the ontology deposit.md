## What happened

### 1. What the convention actually requires

The bundled `Publications/ITcon_template2023.dotx` shows one example reference —
`Turk Z. (1991). Integration of Existing Programs Using Frames, …` — a pre-APA-7 house style. The
**current** ITcon authors' guide says, verbatim, *"The APA 7th edition referencing style must be
used"*, alphabetical, author–date in text, *"Include a DOI as a URL whenever available."* The
manuscript's 41 existing entries are already APA 7. **The template is the stale artefact, not the
paper** — recorded as an out-of-scope observation, not fixed.

### 2. Why the citation could not point where the comment said

The comment names `Erarchitech/design-grammar-system`. Checking what that repository actually
contains:

- **539 tracked files** of `DG_OBSIDIAN/` — the PhD knowledge vault, session notes, decisions
- **121 tracked files** under `Publications/` — draft manuscripts *including this one under review*,
  and `01_Comments/` holding review files named after their authors
- no tracked secrets (checked: `.secrets/`, `.env`, key-shaped strings — all clean)
- **no `LICENSE` at all**, while `[P99]` calls it an *"open ontology project"* and AVAILABILITY
  promises release *"under the same licence"*

Two consequences follow. Licensing that repository would declare the vault and the unpublished
drafts openly licensed. Citing it would land a reviewer, following the citation, on the manuscript
they are reviewing and on another reviewer's named comments.

The author chose **route (A): a separate citable deposit** — which is what AVAILABILITY had already
promised (*"deposited at an open, citable archive"*). Originals stay in the development repository;
the deposit is a copy.

### 3. The deposit

`https://github.com/Erarchitech/design-grammar-ontology` · tag `v1.0.0` · 329 files · 4.9 MB.
Local working copy at `c:/Users/Admin/source/repos/design-grammar-ontology`.

Contents follow AVAILABILITY's own enumeration: core module and catalogue, three alignment
extensions, SHACL shape set and disjointness overlay, four normative specifications, the rule-shape
catalogue, four schema migrations, and — under `services/` — the graph data service, the reasoner
sidecar and the Grasshopper plugin, sources only. Build output, IDE caches and dependency trees
excluded (345 tracked `bin/obj` files, `__pycache__`, `node_modules`, `DG/.vs/`).

**Licensing**, following the practice of comparable AEC ontologies (Brick ships schema and code
under BSD-3-Clause; ifcOWL declares `cc:license` CC BY 3.0 in its RDF header):

- **Apache-2.0** — services, code, migrations. Canonical 201-line text; one line substituted:
  `Copyright 2026 Evgenii Ermolenko`.
- **CC BY 4.0** — `ontology/` and `spec/`, declared as a `cc:license` triple inside each ontology
  header so the licence travels with the file, not only with the repository.
- `CITATION.cff` so GitHub shows a citation block and Zenodo reads authorship when the DOI is minted.

### 4. The verification that mattered

The paper claims a reader can recount Table 3 from the deposited core module. That claim was checked
against the deposit itself, not the source tree and not the draft's prose:

| Claim | Result |
|---|---|
| Table 3 totals 62 / 43 / 68 | **62 / 43 / 68** — match |
| Table 3 per layer 18 / 15 / 13 / 12 / 4 | **18 / 15 / 13 / 12 / 4** — match |
| Annex C standards axioms 9 / 9 / 16 | **9 / 9 / 16** — match |
| Annex C two disjointness axioms | **2** — match |
| Annex C seventeen SHACL node shapes | **17** — match |

**The finding that shaped the deposit:** `ontology/DesignGrammar.owl` — the unversioned file any
reader would take for "the core module" — yields **143 / 38 / 66** and does **not** reproduce
Table 3. Only the `-V7` bundle does. Had the deposit shipped the unversioned file under that name,
both the Table 3 caption and AVAILABILITY's recountability sentence would have been false. The
deposit ships `DesignGrammar-V7.owl`, and its README names that file and carries the shell commands
to recount the totals and the layer split — so the claim is checkable rather than asserted.
