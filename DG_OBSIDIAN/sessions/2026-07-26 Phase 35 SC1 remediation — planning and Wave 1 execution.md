### Deliberate deviation from the AI-SPEC

The spec names `scripts/build_frame_ablated.py` as the Corpus A generator. Rejected: the
RawCanvas → `cgContextJson v1` serialization is C#-only (`ComputgraphContextSerializer` +
`CanvasAnnotationParser`) and **no serialized-context fixture exists in Python-land** —
verified, `data-service/fixtures/` held only the few-shot. A Python generator would have to
re-implement the serializer under test, and a corpus whose input is produced by a
reimplementation of the code being graded is worse than the drift it was meant to prevent.
Corpus A is therefore generated by a **DG.Tests golden-file emitter** using the production
path; Python only reads the two committed artifacts.

### The actual SC1 fix (35-08)

Root cause was never a model-capability limit. The old few-shot fed the model input group
nicknames that *already conformed* (`11_IntF_ParSplitAt`) and justified every proposal with
*"matches the Interface naming grammar"*. That demonstration teaches: **propose only when
the surface name already matches.** On an untagged canvas nothing matches, so faithful
imitation yields zero proposals. DeepSeek did not fail — it executed the demonstration.

Every harmful property inverted, each independently asserted: non-conforming input
nicknames, plainly non-canonical node nicknames, `suggestedName` visibly different from the
observed name, graph-evidence-only rationales (the words "grammar"/"convention" now
forbidden by test), 5 heterogeneous examples instead of 2 homogeneous Interfaces, varying
confidence, abstention placed mid-list. Plus `prompts/recognition_system.md` — the system
prompt that **never existed**, though `req.system` is declared at `llm_gateway.py:40` and
honoured by all three adapters.

### Gateway defects closed (35-07)

- **D6 temperature** — uncontrolled on both cloud adapters; any measurement taken before
  this was an anecdote, not a result.
- **UAT F1 truncation** — `max_tokens: 4096` hardcoded in all three adapters, and the stop
  reason discarded, so hitting the cap was undetectable. Now caller-sized with
  `truncated`/`finish_reason` surfaced.
- **OpenAI `max_tokens` → `max_completion_tokens`** — the old body would have **400'd**
  against o-series and GPT-5.x models.
- Backward compatible: with `options` omitted every adapter reproduces its prior body
  exactly, so `/llm/generate`, the n8n workflows and `generate_validated_cypher` are
  untouched. `GenerationOptions` is deliberately **not** on `GenerateRequest` — that is the
  public route body, and `max_tokens: 1000000` there would be a cost-DoS.

## 3. Two findings during execution

### F4 was already fixed — in a parallel session

Found mid-execution that `CanvasListenerComponent.cs` already carried the F4 fix
(`f2f518c`), and the user had verified it live on UrbanBlock_V7 (`a82ab03`) while this
session ran. Plan 35-09's Tasks 1 and 4 were therefore already satisfied; skipped rather

### A latent parser bug — found, planned, not yet fixed

`ComputeHostPatternIds` resolves a pattern's host by **document order**, so a Procedure
group listing a transitively-nested pattern can silently drop `PATTERN_HOST_TO`. Full
write-up: [[debugging/Phase 35 latent parser bug — pattern host resolved by document order|latent parser bug]].
Fix planned as **35-16** (Wave 2). Not reachable today — the fixture lists direct children
only — but a real canvas emits transitive containment.

## 4. Plan-authoring imprecisions worth remembering

Two acceptance criteria I wrote were sloppier than the code they graded:

- **35-06** asserted `cg_schemas.py` "contains no reference to `tagged`" as a bare grep. It
  matched 5 times — all prose in docstrings plus the field description the plan itself
  mandates (*"cite… adjacent tagged procedure"*). Verified the real intent with an AST scan
  instead: zero relational identifiers in executable code. **Grep-shaped criteria should
  scope to code, not to the file.**
- **35-08** was scoped as pure authoring "no code changes", but `test_cg_recognition.py`
  asserted the old `{input, expected}` fixture shape, so the reshape left the suite red.
  Updated that one assertion rather than shipping red, and added a regression guard that no
  demonstrated rationale may ever cite the grammar again. **A plan that changes an artifact
  must own the assertions on that artifact, even when they live in another plan's file.**
