## Findings that changed the plan

- The upstream Desktop Windows pipeline is **MSIX-only**. D-04 (NSIS) becomes a degram-only NSIS target.
- Hermes reads `HERMES_HOME` from the **Windows registry** and can attach to a running host backend. Every built-in tool registers at import. Auxiliary LLM calls have an OpenRouter/Nous discovery chain. The OSV preflight and model catalog make background calls.
- DG auth sends every Bearer to the connector path and requires CSRF for every user principal. There is no company concept. The gateway falls back to Ollama silently and has no streaming. nginx cannot stream.
- Model Viewer gets a **server-wide Speckle read token** in the browser.
- pyRevit Routes defaults to binding **0.0.0.0** with no authentication. This PC already has `host = "127.0.0.1"` (pyRevit 6.5.3).
- `genpro` is an OpenAI-compatible router. MiMo issue #44 (tool-history 400) is a risk that plan 16 probes.
- `apps/degram` has no `node_modules`/`.venv`. ui-v2 vendors only latin fonts.
