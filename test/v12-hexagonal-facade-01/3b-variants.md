## V4 — наклон сот (развёртка 2026-10-05)

`Наклон чет сот` и `Наклон нечет сот` прогнаны сеткой −2…2 × −2…2 (F1 = 6000), `Выступ панелей` — 0 / 150 / 300 / 600 / 1000. После прогона все три слайдера возвращены (−1 / +1 / 300).

|---|---|---|---|---|---|---|
| **−1** | **+1** (V1) | 125 / 100 | 0 | 0 | 0 (0.000) | 0 |
| **−1** | **0 (V4)** | 125 / 100 | **14** | 0 | 0 | 0 |

| любой | −1 | 124 / 99 | 21…49 | **2** | 0 | 0 |
| любой | −2 | 123 / 98 | 26…54 | **4** | 0 | 0 |

- **R3 не реагирует на наклон**: отклонение вершин от уровней = 0 во всех 25 сочетаниях — вершины сот всегда на отметках.
- **Наклон ломает планарность панелей B**: плоскими они остаются только при паре −1 / +1; иначе 14–54 панели скручиваются, отклонение углов от плоскости 1.4–3.6 м (V4: max 3.63 м, медиана нарушителей 1.42 м; ряды на z ≈ 59 и 104 м).
- `Наклон нечет сот` < 0 даёт лишние провалы R11 (модули 1-го этажа) и уменьшает число объектов.
- `Выступ панелей` на измеряемую геометрию не влияет (0…1000 — без изменений).

**Выбор (решение владельца 2026-10-05):** V4 = `Наклон нечет сот` **+1 → 0** (чёт −1, F1 = 6000) → нарушает только **R6** (14 панелей). R6 снова рабочее правило; **R3 — контрольное** (проходит во всех вариантах).
