## Наблюдения, влияющие на тест

1. **Нет слайдеров этажности, высоты этажа и числа модулей по периметру** — основа фасада (уровни, контур) по-видимому приходит из геометрии Rhino. Варианты строятся на слайдерах формы сот, а `R_FAC_HEIGHT_MAX_50_V` будет одинаковым во всех вариантах (контрольное правило).
2. **19 из 27 слайдеров без имени.** PARAMETER REINSTATE сопоставляет параметры по ParameterId, поэтому каждому слайдеру, который войдёт в PARAMETER STATE, нужно дать уникальное понятное имя до первого захвата Design State.
3. **«Group B Panel Ratio» уже существует** — сверить его формулу с определением `hasAspectRatio` в [RULES.md](RULES.md) (высота / ширина), а не пересчитывать заново.
