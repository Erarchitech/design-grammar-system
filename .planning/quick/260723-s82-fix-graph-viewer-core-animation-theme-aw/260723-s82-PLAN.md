# Quick Task 260723-s82: Theme-aware transparent thinking-core GIFs

## Problem

The Graph Viewer thinking-core sphere (shown while a prompt is processed) composites
`/dg-think-sphere.mp4` over a **painted dark radial backdrop** with a `lighter` blend
(`graphEngine.js` `drawThinkingCore`). On the light paper background this backdrop reads
as a black contour around the core. The user pre-produced two transparent-background GIFs:

- `docs/DG_Think_Animation-black.gif` → for **dark** mode
- `docs/DG_Think_Animation-white.gif` → for **light** mode

## Key constraint

`ctx.drawImage()` of an animated GIF renders **frame 1 only** — the video-frame-blit
pipeline cannot be reused. Solution: DOM `<img>` overlay positioned by the engine.

## Approach

1. **Assets**: copy the two GIFs to `ui-v2/public/` as `dg-think-dark.gif` /
   `dg-think-light.gif` (served at site root, same as the old mp4). Delete the
   now-unreferenced `dg-think-sphere.mp4`.
2. **graphEngine.js** — replace the `<video>`+canvas-blit thinking core with an `<img>`
   DOM overlay:
   - `_initThinkImg()` (replaces `_initThinkVideo()`): create `<img>`, absolute-positioned,
     `pointer-events:none`, opacity 0, inserted via `canvas.insertAdjacentElement("afterend")`
     — same stacking layer as the canvas, below UI panels. `src` chosen by
     `document.documentElement.dataset.theme`; a `dg-theme` listener swaps src live.
   - `drawThinkingCore(cx,cy,base,t)`: no dark backdrop, no `lighter` composite, no circular
     clip (GIF is transparent). Position/scale the img each frame from screen-space
     `cx,cy` (CSS px — canvas transform is DPR-only, so coordinates map 1:1 to CSS)
     at 2.2R square, opacity = `_think`.
   - Procedural fallback (img load error) becomes theme-aware: `TH.ink`-based
     source-over glow instead of white-on-dark `lighter`.
   - `startThinking()`/`updateThinking()`: drop video play/pause/self-heal plumbing.
   - `stop()`: remove img + `dg-theme` listener (re-created on `start()`).

## Verify

- `npm --prefix ui-v2 run build` passes.
- No remaining references to `dg-think-sphere.mp4` in `ui-v2/src`.
