<plan_decisions>
- **Additive-only grammar extraction (DEVIATES from RESEARCH Pattern 1).** RESEARCH recommends interpolating the new constants into `CanvasAnnotationParser`'s regex fields. This is REJECTED: `CanvasAnnotationParserTests.CanvasAnnotationParserSource_UsesCompiledAnchoredGrammarRegexes` (lines 130-144) asserts the exact literal regex strings (e.g. the quoted `^OBJECT - (?<name>.+)$` form) appear verbatim in the parser source. Interpolating constants removes those literals and breaks that locked test. `CanvasAnnotationParser.cs` MUST NOT be edited. Single-source is instead enforced by a consistency test that reads the parser source and asserts each `CanvasAnnotationGrammar` constant's value appears in it — catching drift in either direction.
- **ProcIndex is the full NN token uniformly across all Kinds** (adopts RESEARCH Open Question 1 recommendation). The factory receives the full NN (e.g. `11` = algorithm 1, procedure ordinal 1), not an ordinal needing an implicit algorithm digit. NN < 10 is invalid (SplitNn needs ≥ 2 chars) and is rejected.
- **Pattern naming: idx slot is always the auto-assigned next-free integer; a provided Name is the optional trailing label** (`<NN>_Pat_<k>` or `<NN>_Pat_<k> <Name>`). This supersedes a literal `<NN>_Pat_<Name>` reading because a Name with spaces would parse ambiguously (grammar idx is `[^ ]+`), breaking the TAGC-03 round-trip. Honors CONTEXT "auto-incrementing the pattern index (next free 11_Pat_k)".
</plan_decisions>
