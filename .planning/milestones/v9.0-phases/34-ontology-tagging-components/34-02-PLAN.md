<plan_decisions>
- **`dg.objectClassIri` persisted via `GH_Document.ValueTable`** (resolves CONTEXT.md "Claude's Discretion" #2 using RESEARCH Addendum §3). `doc.ValueTable.SetValue("dg.objectClassIri", iri)` / `GetValue(key, "")` — serialized into the .gh/.ghx, invisible on canvas. Do NOT construct `new GH_SettingsServer(...)` (that writes to %AppData%, not the document).
- **Scribble creation per RESEARCH Addendum §1**: `new GH_Scribble()` → `CreateAttributes()` → set `Text` + `Font` (`new Font("Microsoft Sans Serif", ~30f)`) → `Attributes.Pivot = new PointF(x, y)` (top-left) → `doc.AddObject(scrib, false)` inside `ScheduleSolution` → `Grasshopper.Instances.InvalidateCanvas()`. There is NO writable `Bounds`; the scribble auto-sizes from Text+Font. Exact rendered size/placement is a human-verify item.
- **AlgorithmIndex is the single leading NN digit** (1..9), default 1 — validated so the `<n>_ALGORITHM` scribble stays grammar-legal.
</plan_decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GH input → canvas mutation | User-supplied ObjectName / AlgorithmIndex / Class IRI crosses into scribble text and document metadata |
| .gh file → parser | Anyone who can edit the .gh can author scribbles that match the convention (accepted — single-user local tool) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-02 | Tampering | ObjectMarkerComponent (ObjectName) | medium | mitigate | Validate ObjectName via `CanvasAnnotationNameFactory.ValidateName` before building the scribble; on a reserved-token/whitespace/newline name surface `AddRuntimeMessage(Warning)` and create nothing (V5, ASVS L1). |
| T-34-03 | Spoofing | .gh file → CanvasAnnotationParser | low | accept | Any editor of the .gh can fake an `OBJECT - X` scribble. Accepted per the tool's single-user local threat model — manual tags are ground truth by design; no additional control this phase. |
| T-34-SC | Tampering | package installs | low | accept | No npm/pip/cargo/NuGet installs this phase. |
