<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GH input → canvas mutation | User-supplied Kind/Name/ProcIndex crosses into a group nickname and canvas structure |
| .gh file → parser | Anyone editing the .gh can author a convention-matching group nickname (accepted — single-user local tool) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-04 | Tampering | EntityTagComponent (Name) | medium | mitigate | Validate Name via `CanvasAnnotationNameFactory.ValidateName` before building the nickname; a reserved-token/whitespace/newline Name surfaces `AddRuntimeMessage(Warning)` and creates no group (V5, ASVS L1). Prevents a Name re-parsing as a different Kind. |
| T-34-05 | Tampering | EntityTagComponent (canvas mutation) | low | mitigate | Defer every group create/membership mutation via `doc.ScheduleSolution` (SDK constraint) so a solve-time mutation cannot corrupt the document; wrap the scheduled callback in try/catch. |
| T-34-03 | Spoofing | .gh file → CanvasAnnotationParser | low | accept | Any editor of the .gh can author a convention-matching group. Accepted per the single-user local threat model — manual tags are ground truth by design. |
| T-34-SC | Tampering | package installs | low | accept | No npm/pip/cargo/NuGet installs this phase. |
</threat_model>
