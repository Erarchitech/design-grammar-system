<objective>
Create `CanvasAnnotationParser` in DG.Core: the pure-logic classifier that turns a `RawCanvas` (extractor output) into a `CgContext` by matching scribble text and group nicknames against the DG Canvas Annotation Convention grammar (RESEARCH §4). Conforming names become typed Computgraph entities; everything else falls into the untagged set. The parser never guesses — guessing is Phase 35's LLM job.

Purpose: CGSR-02 — deterministic, testable convention parsing is the seam that the Phase 34 tagging components (which WRITE these exact names) and the Phase 35 recognizer (which reads the untagged remainder) both depend on.
Output: `Parsing/CanvasAnnotationParser.cs` + a unit-test matrix.
</objective>

  <action>
    Create `CanvasAnnotationParser` as a `static class` in namespace `DG.Core.Parsing`, following the `SwrlRuleParser.cs` static-class + `static readonly Regex` pattern. Public entry: `public static CgContext Parse(RawCanvas raw)`. Throw `ArgumentNullException` only for a null `raw` (API-boundary guard) — NEVER throw for unrecognized annotation text (CONTEXT decision #2: route to untagged instead).

    Define one compiled regex per grammar rule (all anchored `^...$`, `RegexOptions.Compiled | RegexOptions.CultureInvariant`, named capture groups):
    - object: `^OBJECT - (?<name>.+)$` (scribble)
    - algorithm: `^(?<alg>\d+)_ALGORITHM$` (scribble)
    - procedure: `^(?<nn>\d+)_Proc - (?<name>.+)$` (group)
    - pattern: `^(?<nn>\d+)_Pat_(?<idx>[^ ]+)( (?<name>.+))?$` (group)
    - variable: `^(?<nn>\d+)_Var_(?<name>.+)$`; constant: `^(?<nn>\d+)_Const_(?<name>.+)$`; emergent: `^(?<nn>\d+)_(?:Emg|Emr)_(?<name>.+)$` (group)
    - interface: `^(?<nn>\d+)_IntF_(?<name>.+)$` (group)

    Keep regexes LINEAR (literal prefixes + a single greedy `.+` capture) — no nested quantifiers — to preclude catastrophic backtracking (see threat model T-32-03).

    Classification flow: (1) iterate `raw.Scribbles`, match object → set `CgObject` (Source="tagged"), match algorithm → create/lookup `CgAlgorithm` by Index. (2) iterate `raw.Groups`, dispatch nickname through the ordered regex candidates; on match, decompose NN via a helper `(int alg, int procOrdinal) SplitNn(string nn)` = first char → alg, remainder → procedure ordinal; look up (or lazily create) the target `CgAlgorithm` and `CgProcedure` (Index == the full NN integer) and append the typed entity. Assign deterministic ids per RESEARCH §5 scheme `cg:<alg>:<kind>:<conventionName>` (e.g. `cg:1:proc:11`, `cg:1:var:11_Var_SpansCount`). Copy `RawGroup.MemberIds` onto the entity's `MemberIds`.

    Ensure `raw.Definition`, `raw.Project`, `raw.Nodes`, `raw.Wires` pass through onto the resulting `CgContext` unchanged; set `CgContext.SchemaVersion = "cg-context-1"`.

    Add `CanvasAnnotationParserTests` (namespace `DG.Tests`) covering every `<behavior>` line with `[Fact]`/`[Theory]`, naming `Parse_<Scenario>_<Expected>`. Include a `[Theory]` row with a Cyrillic parameter name (e.g. `11_Var_Высота`) asserting the name survives verbatim.

  <action>
    Extend `CanvasAnnotationParser.Parse`:

    Untagged routing: any `RawGroup` whose nickname matches NO grammar rule → append to `CgContext.Untagged.Groups` (Nickname + MemberIds copied). After all groups processed, compute the set of member ids claimed by any tagged entity; every `raw.Nodes[i].InstanceId` NOT in that set → add to `CgContext.Untagged.NodeIds`. Never fabricate a typed entity for an unmatched name.

    Emr tolerance: the emergent regex already accepts `Emg|Emr` (Task 1). When the matched literal was `Emr`, append to `CgContext.Warnings` a message of the form `'<nickname>' normalized to Emergent (Emr→Emg)` (mirror RESEARCH §5 wording). The entity Kind is still `Emergent`.

    Pattern nesting: after patterns are created, resolve `HostPatternId` — for each pattern group, if its group id appears in another pattern group's `RawGroup.NestedGroupIds` (or, fallback, if its MemberIds are a strict subset of another same-procedure pattern's MemberIds), set the child's `HostPatternId` to the host pattern's `Id`. Bound the host-resolution walk to a fixed max depth (e.g. 32) and detect cycles; on exceeding the bound, stop and append a warning rather than looping (threat model T-32-04).

    DataType + slider domain inference: for a `Var_`/`Const_`/`Emg_` parameter group, inspect its member `CgNode`s to pick the "primary" input by precedence slider > value list > panel. If the primary is a slider (`CgNode.Slider != null`): `DataType = IsIntegerSlider ? Integer : Float`, `Domain = node.Slider`. Value list → `Text` (or `Integer` if the group name/nodes indicate — default `Text`), panel → `Text`, boolean toggle component → `Boolean`. If no member resolves a dataType, leave `DataType = null`. If members disagree on the primary type, keep the precedence winner and append a warning naming the parameter. Never throw.

    Add tests to `CanvasAnnotationParserTests` for each `<behavior>` line: untagged group + untagged node, Emr warning, nested-pattern HostPatternId, integer-slider inference (Integer + domain), and the ambiguity-warning case.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .gh canvas text → parser | Scribble text and group nicknames originate from a Grasshopper definition file that may be authored/edited by anyone. This untrusted text crosses into the regex-driven classifier. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-32-03 | Denial of Service | grammar regexes | medium | mitigate | All grammar regexes are anchored (`^...$`) with literal prefixes and a single greedy `.+` capture — no nested/overlapping quantifiers — so matching is linear and immune to catastrophic backtracking (ReDoS). `RegexOptions.Compiled | CultureInvariant`. |
| T-32-04 | Denial of Service | pattern-nesting resolution | medium | mitigate | Host-chain resolution is bounded to a fixed max depth with cycle detection; exceeding the bound appends a warning and stops rather than recursing/looping unboundedly on a maliciously self-referential group graph. |
| T-32-05 | Tampering / Spoofing | untagged classification | low | mitigate | The parser NEVER promotes an unmatched name to a typed entity (CONTEXT decision #2). Malformed/adversarial nicknames can at most land in the untagged bucket; they cannot forge a Procedure/Parameter identity that downstream persistence (Phase 36) would trust. |
| T-32-06 | Information Disclosure | warnings text | low | accept | Warning strings echo the offending nickname verbatim; nicknames are user-authored canvas labels, not secrets. No credential or path data is surfaced. |

No package-manager installs in this plan — no T-32-SC / legitimacy gate required.
</threat_model>
