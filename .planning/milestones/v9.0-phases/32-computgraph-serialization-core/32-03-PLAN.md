## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-32-07 | Tampering | Deserialize input | medium | mitigate | Version-check-first + `ValidateDeserialized` reject payloads with the wrong `schemaVersion` or missing required identity fields before the model is trusted; unknown enum strings throw rather than silently defaulting. Downstream (Phase 36 MERGE) therefore never persists a malformed/forged Computgraph. |
| T-32-08 | Denial of Service | JSON parse | low | mitigate | `System.Text.Json` default `JsonReaderOptions` caps nesting depth (64) — deeply nested adversarial JSON throws `JsonException`, which is caught and wrapped in `InvalidOperationException` rather than crashing. No custom converter widens this. |
| T-32-09 | Information Disclosure | error messages | low | accept | Error messages include the offending schemaVersion / enum value verbatim; these are contract tokens, not secrets. |

No package-manager installs in this plan — no T-32-SC / legitimacy gate required.
</threat_model>
