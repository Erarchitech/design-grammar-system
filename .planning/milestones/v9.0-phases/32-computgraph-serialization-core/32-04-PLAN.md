    - For every `IGH_DocumentObject` that is a component/param (not a group/scribble): create a `CgNode { InstanceId = obj.InstanceGuid.ToString(), ComponentGuid = obj.ComponentGuid.ToString(), Name = obj.Name, Nickname = obj.NickName, Position = [obj.Attributes.Pivot.X, obj.Attributes.Pivot.Y] }`. Detect nesting: for each other `GH_Group`, if its `InstanceGuid` is contained in this group's `ObjectIDs`, add that child group's id to `NestedGroupIds` (group-id-inside-ObjectIDs = nesting, per CONTEXT). Endpoints are param INSTANCE GUIDs (CONTEXT "open for planning" resolution: stable under renames). Use the `GhCastingHelpers` casting style for IGH_Param access; guard-and-continue on any cast miss (collect nothing, skip) rather than throwing.

    Keep the extractor a PURE traversal: it must NOT classify names into typed entities (that is the DG.Core parser's job) — it only fills nodes/wires/groups/scribbles.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live GH_Document → extractor | The extractor reads a Grasshopper definition opened in Rhino. Component/param/group/scribble content is user- or file-authored; malformed geometry, self-referential groups, or missing sources may be present. |
| extractor output (cgContextJson) → Phase 33 bridge | The `SerializeContext` string is later served over a TCP listener (Phase 33) — its content shape must be trustworthy for downstream MCP clients. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-32-10 | Denial of Service | GH_Document traversal | medium | mitigate | Guard-and-continue on every cast/read (missing `Sources`, null pivot, degenerate slider) rather than throwing; a single bad object cannot abort the traversal. Group-nesting detection is a bounded pairwise scan over the document's groups (no unbounded recursion — nesting is emitted as flat NestedGroupIds and resolved with the depth-bounded walk in the DG.Core parser, T-32-04). |
| T-32-11 | Elevation of Privilege | UI-thread marshalling | low | accept (deferred) | This plan's extractor is a pure synchronous read invoked on-demand; off-UI-thread access (the TcpListener worker thread) is a Phase 33 concern where `RhinoApp.InvokeOnUiThread` marshalling is introduced. Documented as a Phase 33 boundary, not a Phase 32 defect. |
| T-32-12 | Information Disclosure | node names/paths | low | accept | Extracted nicknames/component names/file name are canvas metadata the architect already owns; no credentials/secrets traverse the extractor. FileName uses the document display name, not an absolute filesystem path. |

No package-manager installs in this plan — no T-32-SC / legitimacy gate required.
