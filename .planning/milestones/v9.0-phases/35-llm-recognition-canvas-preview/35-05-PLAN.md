<plan_decisions>
- **Two commits, in this order, and never squashed.** Commit 1 = `memberIds`/`nestedGroupIds` on the two `_Proc` groups. Commit 2 = the `wires[]` array. AI-SPEC §5 *Freeze protocol* item 1: a reference and the artifacts it grades changing in one commit makes the run **void, not merely suspect**. This plan predates any reference file, but the same discipline applies because 35-11 derives Corpus A's reference mechanically from exactly these groups.
- **Wiring is derived from Grasshopper component semantics, not from the Tier-0 rule table.** The author must not open AI-SPEC §4's R1–R6 table while wiring. A `Divide Curve` gets a curve + a count; a `Line SDL` gets start/direction/length; an `Evaluate Curve` gets a curve + parameter; a `Panel` is a terminal display or a source. This is the AI-SPEC's *"the wiring commit must land before `cg_topology.py` exists"* rule made operational — it reduces circularity, and 35-11 stamps `tier0Evidence: false` because it cannot eliminate it.
- **Three nodes stay deliberately isolated:** `n-untagged-01` ("loose panel"), `n-scratch-01`, `n-scratch-02`. They are the corpus's `abstainExpected` set (AI-SPEC §5 minimum-viable-corpus table: 3 abstain nodes on Corpus A) and the positive test case for E5 abstention recall. Wiring them would delete the only honest-abstention evidence Corpus A has.
- **`11_Emr_UpperChord` keeps its deliberate misspelling.** It is the parser's Emr-tolerance test case (Phase 32-02) and must survive untouched.
- **Node set is not extended.** No new components, no relays, no spatially-interleaved grouping. Those are FM-1/FM-2 test material and the AI-SPEC assigns them to Corpus B (`urbanblock_slice`, plan 35-14) precisely because inventing them here would be authoring the adversary and the defence in one hand.
</plan_decisions>
