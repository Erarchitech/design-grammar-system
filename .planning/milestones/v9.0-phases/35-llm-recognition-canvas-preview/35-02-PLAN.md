<plan_decisions>
- **Persistence mechanism (resolves CONTEXT "Claude's Discretion" #1):** `source: recognized` persists via `GH_Document.ValueTable` keyed `dg.recognized.<groupInstanceGuid>` — the proven `ObjectMarkerComponent`/`dg.objectClassIri` precedent, which survives `.gh` save/reopen. NOT a listener in-memory dictionary (dies on Rhino restart) and NOT a sidecar file.
- **RawGroup.Recognized** is a new optional `bool` on the GH-free `RawGroup` (defaults false). The extractor sets it; the parser reads it and sets `Source = recognized ? "recognized" : "tagged"` in place of the current literal `"tagged"` on group-derived entities (Procedure, Pattern, Parameter, Interface). This is the ONE place this phase touches previously-locked Phase 32/34 parser code — additive only, never a change to the classification regex.
- **Threading the doc into TryAddGroup:** `CanvasContextExtractor.TryAddGroup` is currently `static (RawCanvas, GH_Group, IReadOnlyDictionary<Guid,GH_Group>)` with no `GH_Document`. Thread the `GH_Document doc` (already held by `ExtractRaw`) into `TryAddGroup` as a new parameter so it can call `doc.ValueTable.GetValue($"dg.recognized.{group.InstanceGuid}", "false")`.
- **Registry lifetime:** a single shared `internal static class PreviewRegistry` is sufficient for this single-architect, typically-single-canvas-tab tool (35-RESEARCH.md A3). A `DocumentID`-keyed variant is deferred unless multi-document leakage shows up in UAT.
</plan_decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .gh file → CanvasAnnotationParser | Anyone who can edit the .gh (or its ValueTable) can author a `dg.recognized.<guid>` marker without a real recognition run |
| Two independent components → PreviewRegistry | Shared in-process state read/written by the listener and the confirm component |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-35-03 | Spoofing | .gh ValueTable → parser Source | low | accept | A hand-edited `.gh` can inject a `dg.recognized.<guid>` marker without a real recognition. Accepted per the tool's single-user local threat model (same boundary 34-RESEARCH.md accepts for tagged-entity spoofing) — `source: recognized` is provenance-for-audit, advisory not authoritative; Phase 36 treats it as reviewable, not trusted-without-review. |
| T-35-07 | Tampering | PreviewRegistry (shared mutable state) | low | mitigate | `ConcurrentDictionary` removes any cross-thread corruption risk between the UI-thread solve (confirm component) and the marshalled UI-thread write (listener); `Pending` returns a snapshot copy so enumeration cannot observe a torn write. |
| T-35-SC | Tampering | pip/npm/cargo/NuGet installs | low | accept | No new packages this phase — pure additive code against the already-referenced Rhino 8 SDK. |
</threat_model>
