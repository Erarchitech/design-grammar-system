## Wire Contract (LOCKED — identical to Plan 01; the Python client MUST match byte-for-byte)

- Request line (client → listener): `{"type":"<command>","parameters":{ ... }}` — UTF-8, `\n`-terminated.
- Response line (listener → client): `{"bridge":"dg","version":1,"status":"ok","result":<payload>}` or `{"bridge":"dg","version":1,"status":"error","error":{"message":...,"code":...}}` — single line, `\n`-terminated.
- `get_canvas_context` result = the cgContextJson v1 document (JSON object); `get_selection` result = `{"selection":[...]}`; preview commands = `{"supported":false,...}` stub.
- Client behavior: on `status == "error"` in the envelope → raise a structured error carrying the envelope's `error.message`/`error.code` (502). On socket refusal/timeout → `GH_BRIDGE_UNREACHABLE` (503). Otherwise return `envelope["result"]`.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-33-06 | Tampering / Denial of Service | gh_bridge socket read | high | mitigate | Bounded `CONNECT_TIMEOUT_SECONDS`/`READ_TIMEOUT_SECONDS` + `MAX_RESPONSE_BYTES`-bounded readline so a malformed, oversized, or never-terminating response cannot hang the request or exhaust memory; refusal/timeout → structured 503, never a hang (BRDG-04).
