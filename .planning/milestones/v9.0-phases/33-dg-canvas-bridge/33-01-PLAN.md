## Wire Contract (LOCKED — shared verbatim by Plans 01, 02, 03)

Transport: raw TCP, UTF-8, newline-terminated (`\n`), no BOM, one JSON object per line, one client at a time.

- Request line (client → listener): `{"type":"<command>","parameters":{ ... }}`
- Response line (listener → client), always single-line, always includes the two handshake fields:
  - Success: `{"bridge":"dg","version":1,"status":"ok","result":<payload>}`
  - Error:   `{"bridge":"dg","version":1,"status":"error","error":{"message":"<text>","code":"<CODE>"}}`

Per-command `result` payloads (v9.0):

| Command | result payload |
|---------|----------------|
| `get_canvas_context` | the cgContextJson v1 document as a nested JSON object (parsed, NOT a quoted string) |
| `get_selection` | `{"selection":["<instanceGuid>", ...]}` |
| `preview_structure` / `clear_preview` / `get_preview_status` | `{"supported":false,"command":"<name>","message":"Not supported in v9.0 (Phase 35)."}` |

Error codes: unknown command → `UNKNOWN_COMMAND`; unparseable/oversized/BOM-broken line → `BAD_REQUEST`.

- Static class `CanvasBridgeProtocol`: constants `BridgeName`="dg", `Version`=1; `bool TryParse(string line, out CanvasCommandRequest request)` (strips a leading BOM `U+FEFF`, guards null/whitespace/oversize); `string BuildOk(object? result)`; `string BuildError(string message, string code)`; `JsonSerializerOptions` matching the ComputgraphContextSerializer convention (camelCase, no indent, no BOM).
- Class `CanvasCommandDispatcher`: constructor takes `IReadOnlyDictionary<string, Func<CanvasCommandRequest, object?>> handlers`; method `string Dispatch(string line)` — parse → allow-list lookup → invoke → `BuildOk`; unknown → `BuildError(..., "UNKNOWN_COMMAND")`; parse failure → `BuildError(..., "BAD_REQUEST")`; handler exception → `BuildError(ex.Message, "HANDLER_ERROR")`; static `object StubResult(string command)` returning the not-supported payload.
- Static class `CanvasListenerRequestKey`: `string Build(bool run, int port)` returning `"{run}|{port}"` (invariant lowercase bool).
