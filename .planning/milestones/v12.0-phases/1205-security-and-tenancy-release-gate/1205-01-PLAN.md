<objective>
Establish the secret inventory and the known-default policy, and have the owner create the gitignored `.env` BEFORE any authorization enforcement lands, so the owner cannot be locked out (orchestrator fact 5; D-05) and so every later `docker compose` rebuild that runs in-container tests keeps working once 1205-09 makes secrets required (D-10).

Rotation of the live values (D-13) is deliberately NOT done here — it runs in 1205-18 against the finished code, so this plan only copies current live values for pre-existing keys.

Output: `.env.example`, `data-service/secrets_policy.py` (+ tests), `tools/security/check_env_file.py` (+ tests), and an owner-created `.env` (untracked, never read by Claude).
