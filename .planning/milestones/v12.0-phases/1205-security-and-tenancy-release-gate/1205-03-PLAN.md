<objective>
Make every Grasshopper call to data-service carry its project-bound `dgc_` connector token (D-04, Correction 5) before the server starts requiring it (1205-10), and make CONNECTOR behave correctly when a multi-user deployment withholds the Neo4j bundle (D-07). Authentication is required in both profiles (D-19).

Purpose: server-side enforcement on `/validation/publish` and `/computgraph/publish` would otherwise break every existing canvas silently (RESEARCH Pitfall 3). The header logic lives in DG.Core so xUnit can test it without the Grasshopper SDK; the GH wiring stays under `#if GRASSHOPPER_SDK`.

Output: new `DataServiceRequestAuth.cs` + tests, three new error templates, Token inputs on VALIDATOR and COMPUTGRAPH PUBLISH, CONNECTOR no-bundle handling, and a credential-free `ConnectionInfo` default.
</objective>
