<objective>
Ship the LLM repeatability measurement driver `repeat_sweep.py`, the D-12 prompt-freeze script, and the additive LLM-report emitter with its own schema. The driver measures the two D-09 subjects — recognition (`cg_recognition.recognize_structure`) and rule-ingest Cypher generation (`dg_context.generate_validated_cypher`, type `rule_ingest`) — at k=10 samples per item per provider, resolve-once per provider, never pooling providers (D-13). Each sample flows through `CassetteAdapter(sample_index=1..k)` (1204-03), is classified by `outcome_taxonomy.classify` and stamped with the `LLM_SAMPLE_PROVENANCE_FIELDS` block via `assert_llm_sample_provenance` (1204-04), and reads the served-model/response-id/fingerprint fields 1204-02 added. Rule-ingest calls send no `GenerationOptions`, and the report records temperature as "not sent — provider default" (D-10). A D-12 freeze script renders the five rule-ingest inputs once (n8n "Build LLM Prompt" node logic) against a fake renderer in tests. D-17 metrics are computed per item at two normalization levels with distinct-output count, modal-agreement rate, and Wilson 95% CI via `scoring.wilson_interval`; rates fire only at n ≥ 5. D-21 regeneration re-runs the report from committed cassettes in replay mode and asserts byte-identical JSON, labelled "scoring-pipeline determinism". D-24's `report_schema_llm.json` is its own schema with no shared/poolable field and no accuracy/expected-label field (D-18).

Purpose: ALGN12-15/ALGN12-16 require measured determinism and "reproducible or explain why" evidence. 1204-02/03/04 built the primitives (provenance fields, per-sample cassette keys, outcome taxonomy); this plan wires them into a runnable measurement and a report that structurally cannot be pooled with the deterministic report. Without it the benchmark has inputs but no instrument.

Output: new `repeat_sweep.py`, `freeze_rule_ingest_prompts.py`, `report_schema_llm.json`, `test_repeat_sweep.py`, and an additive edit to `report.py` (existing recognition-eval report output unchanged).
</objective>
