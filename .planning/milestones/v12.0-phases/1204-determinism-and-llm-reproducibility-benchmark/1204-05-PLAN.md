<objective>
Ship the deterministic repeat runner and its report schema/emitter: a new `tools/de01/run_de01_repeat.py` CLI that imports the four `legs.py` runners and `report.compare_legs` verbatim (D-01), runs N=10 iterations split across ≥2 `docker compose restart` batches recording container id + start time per batch (D-05), computes `projection_hash.verdict_projection_hash` per leg per iteration, runs `compare_legs` per iteration and records `silent_disagreement_count`, classifies every leg `evaluator|relay` (D-02), pins the replay leg's run id to iteration 1's publish (D-06), collects the D-07 config pins, and applies the D-08 N/N gate before emitting a JSON report validated against the new sibling `report_schema_repeat.json` plus an MD report carrying the literal non-proof statement. The runner's core is unit-testable: leg callables and the restart callable are injectable so tests run hermetically under `-k "not live"`.

Purpose: DE-01 today proves cross-leg agreement on one pass, but says nothing about repeatability. 1204-01 shipped the projection-hash primitive; this plan is the runner that uses it to falsify (not prove) determinism across fresh process lifetimes. Without it, the milestone's central ALGN12-15 claim has no measured support and no gate.

Output: new `tools/de01/run_de01_repeat.py` (runner + pinned-replay variant + config-pin collector + JSON/MD emitters + live CLI), new `tools/de01/report_schema_repeat.json` (sibling schema), and new runner-test classes appended to `tools/de01/tests/test_repeat_runner.py` per 1204-01's extension contract.
</objective>
