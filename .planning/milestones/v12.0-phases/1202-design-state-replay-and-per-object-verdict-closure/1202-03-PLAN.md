<objective>
Align the v2 serializer and collapse the two independent payload readers into one (ALGN12-09's
"v2 serializer/readers aligned ... or an explicit exclusion contract" deliverable).

Purpose: today `ObjState.ClassIri` is load-bearing for `DesignStateBindingService` but absent from
the serialized DTO, so a replayed Design State cannot re-bind to its ontology class (D-05). And
two readers of the same payload disagree: the serializer enforces `version == "2"` strictly while
`TryParseDesignState` never checks version at all, sniffing structure instead (D-07). D-09 makes
them one reader.
Output: `ClassIri` as a normative optional DTO member; an explicit version check; one reader.

Sequencing note carried from RESEARCH.md Pitfall 2 and honored by the task order below: the two
readers deserialize into *structurally different targets* — the serializer goes through a private
DTO hierarchy and maps into the domain model by hand (`FromDto`), while `TryParseDesignState`
deserializes straight into the domain model and then needs a manual `Parameters` backfill because
`ParamState.Parameters` is a getter-only `Collection<T>` that `System.Text.Json` silently skips.
Task 2 proves parity on the inputs the inline path covers **before** Task 3 deletes it.
</objective>
