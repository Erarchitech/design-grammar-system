<objective>
Establish ALGN12-08's identity classification and ALGN12-09's canonical state hash + membership
manifest: a canonical DesignState projection in both languages, hashed by the already-hardened
Phase 1200 hasher.

Purpose: D-01 says identity is two layers — a capture-event key as the node key, plus a content
hash as a queryable property. Nothing in the repo implements either today (CONTEXT.md's third
disk fact: zero hits for `stateHash`/`canonicalStateHash` repo-wide). This plan builds the
content-hash layer and the capture-event key derivation, in both languages, with cross-language
parity proven by a golden vector before anything downstream trusts the value.
Output: `DesignStateCanonicalProjection` (C#), `design_state_projection.py` (Python), an additive
capture-event overload on `DesignStateIdGenerator`, and the filled-in
`expectedCanonicalStateHash` on the plan-01 replay fixture.

Discretion resolved here:
- **Canonical projection shape (D-02):** a `JsonObject` with keys `capturedAtUtc`, `label`,
  `members`, `objStates`, `paramStates`, `propStates`, `stateId` (canonical-writer sorts keys
  ordinally anyway, so the authoring order is irrelevant — what matters is the key *set*).
  Geometry is omitted by construction.
- **Membership manifest placement:** a `members` array *inside* the projection — not a separate
  artifact. Rationale: a manifest that can drift from the thing it manifests is worse than no
  manifest; folding it into the hashed projection makes membership tamper-evident for free.
- **Capture-event key (D-01):** `DesignStateIdGenerator.ComputeCaptureEventStateId(memberStateIds,
  capturedAtUtc)` → `DS_<hash(sorted memberIds | ISO-8601 capturedAtUtc)>`. The existing
  content-addressed `ComputeDesignStateId(memberStateIds)` is left byte-identical and retained.
- **PropState's missing `CapturedAtUtc`:** documented as **excluded, not normalized**. PropState
  is value-scoped (rule IRI + property IRI + value), not capture-scoped; adding a capture time to
  it would make two identical property assertions captured a second apart hash differently, which
  contradicts the content-hash purpose. The exclusion is stated in the projection doc-comment.
</objective>
