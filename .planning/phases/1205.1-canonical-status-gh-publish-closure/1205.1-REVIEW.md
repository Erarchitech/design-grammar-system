## Source review и contract boundaries

### Python — Unicode и точный container domain

`data-service/evidence_contract.py:226–265` теперь раскрывает BaseModel структурно, принимает только built-in dict/list/tuple как containers и проверяет каждый вложенный элемент. Неподдерживаемые container subclasses, namedtuple, sets, deque, custom mappings/iterables, dataclasses и non-JSON scalar objects явно отвергаются. Dict keys должны быть строками и отдельно проходят Unicode validation. Проверки int overflow и float finiteness сохранены; bool не ошибочно трактуется как integer overflow case.

- Built-in tuple проходит тот же depth accounting, что list; cycles завершаются rejection на bound, shared noncyclic aliases не объявляются cycle.
- Python `str` должен содержать scalar values. In-memory строка из двух surrogate codepoints `\ud83d\ude00` **не** валидный scalar string и отвергается; raw JSON escape pair декодируется в настоящий supplementary scalar и допускается. Это не Unicode normalization и не replacement.
- `decode_evidence_json:268–283` сохраняет rejecting constants/object-pairs hook. `read_envelope_dict:340–363` сохраняет original admitted dict и безопасный ValueError/RecursionError fallback. `parse_envelope_model:331–337`, v2 before-validator `:305–314`, named factory `:366–386` и explicit legacy validator `:474–492` вызывают guard до relevant JSON-mode dump.
- Старый constructor/build defaults не изменены. Поддержка обычных structurally traversed BaseModel records не является обещанием поддержки произвольных custom serializers/overridden model behavior.

### C# — проверки до Parse и до projection

`EvidenceEnvelopeReader.cs:41–88,101–144`: `result` обнуляется до любых guards; malformed literal UTF-16 отвергается до JsonDocument.Parse. Traversal вызывает `GetString()` для каждого string value и получает каждое property.Name, включая unused historical metadata. Исключения lazy decoding ловятся локально и превращаются в false, без blanket catch и без зависимости от repository outer catch. Валидные пары пропускаются целиком; lone low/high surrogate, reversed/repeated pair не пропускаются.

Existing finite-number/duplicate-name traversal остаётся **до Version**. `FullShape`, `Rows`, `RuleResults`, exact version/status parsing, safe-integer range, hash/dgId patterns и ordinal identity semantics этой итерацией не менялись. Legacy row projection не приобретает вердикт из envelope/rule aggregate. `Program.cs:15–34` добавляет только test mode `public-guards`; прежние read/strict/emit branches сохранены. Его strict UTF-8 decoder — свойство harness input, не новое обещание production string API принимать raw bytes.
