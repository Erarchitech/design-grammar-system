`canonicalize(value) -> str` — produce the canonical serialization implementing all six rules:
sort object keys ascending by Unicode code point (use `sorted(..., key=...)` on the raw `str`, which

pointing the caller at the `indeterminate`/`error` statuses as the correct representation for a
non-finite result. Implement the serializer explicitly by recursive walk rather than delegating to
`json.dumps`, so the escaping and number rules are under this module's control and mirror-able in
C# — hand-rolling against the written spec is the deliberate choice recorded in RESEARCH.md
