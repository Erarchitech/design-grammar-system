## Why GAP-3 is a human task, not an automated one

The verifier could not close this gap because the Docker daemon is not running and cannot be started
from an agent shell. That is not a scripting problem an executor can route around: a run against a
down stack produces exactly the report that already exists — three legs typed `error`, one leg real,
`silent_disagreement_count == 0` for a structurally meaningless reason. An executor that "ran DE-01"
and reported success from such a report would be reproducing the gap while claiming to have closed
it.

So Task 1 is a blocking human-verify checkpoint. The human brings the stack up, seeds the graph, runs
the command, and reads the report. The must-haves that depend on that run carry
`verification: backstop`, so a later verifier that cannot confirm them with explicit evidence abstains
to `human_needed` rather than passing them silently.

## Ordering is load-bearing

The live run must happen **after** plans 1200-06 and 1200-07 have landed. 1200-06 changes what the C#
leg's `inputHash` and `outputHash` are for any trailing-zero decimal, and 1200-07 changes how
`compare_legs` classifies a single-non-declarable-status difference — which is precisely the shape the
`ObjectPropertyAtom` row produces when one leg reports `unsupported` and another reports a genuine
verdict. A run against the pre-fix code would tell us nothing about the system that ships. This plan
is wave 5 for that reason.

**Expect the classification of the `ObjectPropertyAtom` row to have changed.** Under the 1200-07 fix,
a pair where one leg says `unsupported` with a warning and another says `passed` or `failed` is now a
**silent disagreement**, not a declared one. 1200-05-SUMMARY records that the `ObjectPropertyAtom`
case previously appeared nested inside `OBJ_GOLD_FAIL`'s declared non-equivalence rather than
standing alone. The live run is the first opportunity to see what the corrected classifier actually
reports for it. If it now reads as a silent disagreement, that is a **genuine finding to record and
escalate** — either the fixture's expected outcomes need the `ObjectPropertyAtom` row to be
structurally isolated from an object that also has a real verdict, or the case genuinely is a silent
divergence that Phase 1201 must resolve. **Do not edit the fixture and do not weaken the
classification to make the number reach zero.** Record what the run says.
