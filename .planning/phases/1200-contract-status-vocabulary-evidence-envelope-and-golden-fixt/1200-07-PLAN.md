<objective>
Close GAP-2 / CR-02: make `compare_legs` treat a lone non-declarable status as never declarable, so
the exact regression DE-01 exists to catch — a leg silently degrading from `passed` to `unsupported`
— is counted as a silent disagreement instead of being waved through as declared.

Purpose: `spec/EVIDENCE-CONTRACT.md` section 8 states in bold that a silent disagreement is a failure
and a declared one is not. Today the shipped code inverts that rule for a single-non-declarable-status
difference, and a green test in the suite certifies the inversion as intended behavior — which is
worse than no coverage, because the next person to fix the logic breaks a passing test.

Output: a one-condition fix in `tools/de01/report.py`, the wrong test replaced, the missing
regression tests added, and the surrounding behaviors re-pinned so the fix cannot over-correct into
classifying every difference as silent.
</objective>

## Why the docstring, not the code, is the specification

`tools/de01/report.py`'s module docstring (lines 4-17) states the rule the phase committed to: a
declared non-equivalence requires that **every differing leg's status** is one of `unsupported`,
`error`, `not_evaluated`, or `indeterminate` **and** carries a non-empty warning. The implementation
never checks a non-declarable leg's status against that requirement at all — line 158's `continue`
skips every non-declarable row, and the only compensating guard is line 169's
`len(non_declarable_statuses) > 1`, which needs two distinct non-declarable statuses before it
fires.

So the code and its own docstring disagree, and the docstring is the one that matches D-14 and
`spec/EVIDENCE-CONTRACT.md` section 8. The fix brings the code to the docstring; the docstring is not
rewritten to match the code.

## Scope guard — D-02 holds

This plan changes a classification condition and its tests. It does not touch the status vocabulary.
`_DECLARABLE_STATUSES` stays exactly the four members it has today — that subset comes from D-05's
situation table and D-02 makes the eight names one-way. If correcting the classification surfaces an
outcome none of the eight statuses can express, that is a **finding recorded for Phase 1201**, not a
ninth status added here.
