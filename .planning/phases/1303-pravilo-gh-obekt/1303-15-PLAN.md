<objective>
Demonstrate Design Grammars on the hand-off of opening requests from MEP to structural engineers, live on the owner's real structural Revit model (a local copy), at today's demo (owner priority 2026-10-20, about 6 hours from capture). Opening boxes are Generic Model families that the structural engineers copied from the MEP model.

Flow:
1. Rules R1–R4 are typed in natural language and become SWRL rules.
2. DG generates the script that computes the properties those rules need and places it on the Grasshopper canvas (Rhino.Inside.Revit) with the DG validation chain.
3. The user presses Run.
4. VALIDATOR checks every box, and the violating boxes turn red in Revit.

Owner decisions, 2026-10-20:
- Rules are evaluated through Rhino.Inside.Revit → GH VALIDATOR.
- DG must create the property scripts itself; the user only runs and checks.
- The model is the owner's real structural model; the path will be given.
- This is plan 15 of Phase 1303.
</objective>
