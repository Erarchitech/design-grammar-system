  <name>Task 3: Revit side — routes, reader, writers, apply loop, ribbon, MCP tools</name>
  <files>apps/dg-revit-connector/dg_revit_mcp/dg_connector_routes.py, lib/dg_connector/revit_io.py, lib/dg_connector/runner.py, lib/dg_connector/signin.xaml, DG.tab/Connector.panel/*.pushbutton/script.py, DG_SharedParameters.txt, tools/dg_connector_tools.py</files>
  <action>
**revit_io.py** (Revit API, IronPython 3.4):
- `collect_scope(uidoc)`: the selection, else `FilteredElementCollector(doc, view.Id).WhereElementIsNotElementType()` model-category instances (not view-specific), capped at 5000.
- `element_row(doc, el)`: category, family (FamilyInstance.Symbol.Family.Name or the type's FamilyName), type, instance + type parameters, and the adaptive count (`AdaptiveComponentInstanceUtils.IsAdaptiveComponentInstance` / `GetInstancePlacementPointElementRefIds`).
- `apply_colours(doc, view, states_by_uid)`: solid-fill overrides in the palette, one transaction «DG mapping colours».
- `clear_colours(doc, view)`.
- `write_parameters(doc, roles_by_uid, states_by_uid)`: one transaction «DG mapping parameters». It binds `DG_Class` / `DG_MappingState` (text, instance, group Data) from the shipped `DG_SharedParameters.txt` (fixed GUIDs) to the categories that allow bound parameters. It switches `app.SharedParametersFilename` and restores it in `finally`, then sets the values.

**runner.py:**
- `start_mapping(uiapp)`: needs a signed-in state; reads the scope; builds descriptors; posts the session; stores the sessionId, documentKey and viewId; colours. Returns `{started, sessionId, message}`.
- A background poll thread every 3 s for the open session uses `loop.next_action`. Revit writes go through one `ExternalEvent` created at startup, never from the poll thread.
- `mapping_status()` and `show_elements(uidoc, uniqueIds)` (`Selection.SetElementIds` + `ShowElements`, missing ids reported).
- A closed document or a switched active document stops the loop with a message; it never writes to another document.

**Routes** (`dg_connector_routes.py`, API `dg_revit`):
- POST `/start_mapping/`
- GET `/mapping_status/`
- POST `/show_elements/` `{uniqueIds}` (≤ 5000)
- POST `/clear_colours/`

POST bodies are parsed with `parse_request_data` (text/plain).

**Ribbon** (`DG.tab/Connector.panel`):
- «Вход»: WPF dialog `signin.xaml` with URL, user, PasswordBox and project; the password is held only for the call.
- «Меппинг DG».
- «Очистить цвета».
- «Выход».

**MCP tools** (`dg_connector_tools.py`): `dg_mapping_status`, `dg_start_mapping`, `dg_show_elements(unique_ids)`, `dg_clear_mapping_colours`, mapped to the routes. Regenerate `tool_contract.json`.
