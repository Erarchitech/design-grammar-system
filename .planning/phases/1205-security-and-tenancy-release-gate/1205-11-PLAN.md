<objective>
Move the browser's data access onto the server boundary (D-06/D-08): one authenticated fetch helper (D-01), the nine direct Cypher sites replaced by named, project-authorised data-service endpoints, the two n8n webhooks replaced by the data-service relay with owner-bound polling, and all Neo4j/n8n credentials deleted from `ui-v2/src/lib` (D-12).

Purpose: after this plan the browser holds no graph credential and cannot choose a Cypher statement; project isolation is enforced by the server, not by which predicate the client builds. The endpoint contract below is authoritative — 1205-12 and 1205-14 implement exactly these shapes (contract-first, so this plan runs in wave 3 in parallel with the flip).

Output: new `apiClient.js`, rewritten `graphApi.js`/`modelApi.js`/`inputGenApi.js`, `connectorsApi.js`/`llmApi.js`/`reasonerApi.js` on apiFetch, and the GraphScreen call-site update.

## Endpoint contract (authoritative for 1205-11, 1205-12, 1205-13, 1205-14)

All paths are relative to `dataServiceUrl` (default `/data-service`). Errors use `{detail: {error, hint, code}}`.

| Method | Path | Request | Response | Implemented by |
|---|---|---|---|---|
| POST | /auth/login | `{username, password}` | 200 `{username, isAdmin}` + dg_session cookie | 1205-07 |

| GET | /auth/me | — | `{username, isAdmin, memberships:[{project, role}]}` | 1205-07 |
| POST | /auth/password | `{currentPassword, newPassword}` | 204 | 1205-07 |
| GET | /projects | — | `{projects:[{project, nodes, role}]}` | 1205-12 |
| POST | /projects | `{project}` | 201 `{project, role}`; 409 `PROJECT_NAME_UNAVAILABLE` | 1205-12 |

| DELETE | /projects/{project}/members/{username} | — | 204; 409 `LAST_OWNER` | 1205-12 |
| POST | /auth/invites | `{username, project, role}` | `{status:"member-added"}` or `{status:"invited", inviteCode, expiresAt}` | 1205-12 |
| POST | /auth/accept-invite | `{inviteCode, password}` | 200 `{username, isAdmin}` + cookie | 1205-12 |
| GET | /graph/{project} | — | `{nodes:[{id, labels, props}], rels:[{source, type, target}]}` | 1205-12 |
