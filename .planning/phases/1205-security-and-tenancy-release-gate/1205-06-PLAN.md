<objective>
Remove the last place tenancy depends on a predicate chosen by someone other than the server: LLM-generated Cypher (ALGN12-17, fail-closed per D-03). The graph-query path relayed under D-08 runs model-written read Cypher through `/mcp neo4j_query` against the single shared database; today a P1 user can ask for P2's data and receive it. This plan adds a deterministic static project-scope validator for `graph_query`, a foreign-literal check and a key-collision finder for rule ingest, and a result-side foreign-entity counter — pure functions in `dg_context.py` with tests. Wiring into the routes happens in 1205-14.

Purpose: `/mcp` cannot be made per-user (RESEARCH Pitfall 2), so the query itself must be proven project-scoped before and after execution. The existing bounded retry loop in `generate_validated_cypher` turns violations into corrective feedback for the model.

Output: extended `data-service/dg_context.py` and new `data-service/tests/test_cypher_project_scope.py`.
</objective>
