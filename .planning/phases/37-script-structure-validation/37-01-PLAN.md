Create `data-service/tests/consult_cassette.py`: a deterministic, network-free stand-in for the provider adapter the consult path resolves at runtime.

Define `ConsultCassetteMiss(Exception)` - raised when replay is requested for a prompt with no recorded entry, so a silently-empty answer can never masquerade as a passing grounding test.

Define `CONSULT_CASSETTE_DIR` as a `pathlib.Path` pointing at a `fixtures/consult/` directory relative to this module's own directory, created lazily only when a recording is written.

Define `DEFAULT_CONSULT_ANSWER` as a canned answer string that cites the `11_Var_HTotal` convention token verbatim and names the `2D Truss Configuration` procedure, phrased as a plausible model reply to "Which parameters drive the truss height?". It must also contain exactly one convention-shaped token that does NOT exist in the Frame subgraph - use `11_Var_HGhost` - so the ungrounded-mention branch has a fixture to exercise.

Define `ConsultCassetteAdapter` with a constructor taking `answer` defaulting to `DEFAULT_CONSULT_ANSWER`, an optional `responses` dict keyed by prompt, and a `raise_on_miss` boolean defaulting to false. Pin the answer at construction time, mirroring how the existing eval cassette pins its negotiated mode once rather than per call. Expose:
- `generate(self, req, api_key=None)` - matching the base adapter's call signature exactly. It appends the request's prompt, model, and provider onto a public `self.calls` list, then returns a response object carrying the canned text. Look up `responses` by prompt first; fall back to `answer`; raise `ConsultCassetteMiss` instead of falling back when `raise_on_miss` is true.
- `self.calls` - a public list so tests can assert the provider was resolved exactly once and the prompt contained the expected subgraph tokens.

The double must construct its return value using the gateway's real response type (imported from the gateway module) rather than a bare dict, so a future field addition to that type surfaces as a test failure instead of silently diverging.

Add three tests to `data-service/tests/test_cg_fixtures.py` covering the double itself: `generate` returns the pinned default answer and appends one entry to `calls`; a prompt present in `responses` wins over the default; a miss with `raise_on_miss` enabled raises `ConsultCassetteMiss`. No network, no `live` marker.
