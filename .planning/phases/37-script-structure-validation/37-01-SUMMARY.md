- `PARAM_HTOTAL_CG_ID` follows the already-committed `test_computgraph_publish.py` fixture's `param` kindLiteral convention (`cg:1:param:11_Var_HTotal`) rather than the raw `CanvasAnnotationParser.ParamId()` C# helper's literal `var` kindLiteral segment — the JSON envelope's id scheme is produced by a separate serializer than the raw parser helper, and introducing a second inconsistent convention inside the same test suite would be worse than matching the existing golden fixture's precedent.
