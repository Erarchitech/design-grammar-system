## 0. Подготовка

1. В браузере откройте `http://localhost:8080/` и убедитесь, что DG открывается. Контейнеры `design-grammars` и `data-service` должны работать.
2. Полностью закройте DeGram: значок в трее → выход. Одного закрытия окна недостаточно.
3. Проверьте установщик в PowerShell:
   ```powershell
   Get-FileHash 'D:\dgb\src\apps\desktop\release\DeGram-Setup-0.1.9.exe' -Algorithm SHA256
   ```
   Хеш должен совпасть с `b4998c6bc542a1fd95a5d5bd6e073312396b2b3712f62935a9234e6d2038a3bd`.
4. Приостановите Kaspersky (F-11) и установите 0.1.9 поверх 0.1.8. Правила доверия для `DeGram.exe` и `agent-payload\bin\degram.exe` оставьте.
5. **Не переименовывайте и не удаляйте** `%LOCALAPPDATA%\DeGram`. В нём лежат прежние чаты проектов, и шаг 3 проверяет именно их: 12 чатов в `v12-hexagonal-facade-01` и 5 в `degram-uat-b`.
6. Подготовьте браузер для действий администратора на шагах 5 и 6: вход в DG под админом и вкладка Connectors под вашим пользователем.

## 1. Запуск

1. Запустите DeGram из меню «Пуск».
2. Ожидается: окно DeGram, внутри страница DG. Если сеанс DG сохранился, сразу откроется стартовый экран из шага 2. Если нет, откроется форма входа DG.
3. Если открылась форма входа, войдите своим пользователем DG.

## 2. Стартовый экран и выбор проекта (F-01, G-22, G-23)

1. Ожидается после входа на стартовом экране DeGram:
   - сверху надпись DEGRAM, под ней Web UI DG с кольцом на главной странице;
   - на главной странице есть **только** Graph Viewer, Model Viewer и PROJECTS;
   - Connectors, DG API Docs, Reasoner и AI Engine **не видны** (G-23);
   - **нет** компактной страницы «DeGram / Read-only workspace / Select a project» со списком кнопок.
2. Если токен сопряжения не сохранён, на этом же экране должна быть панель «Подключение к DG» с полем для токена. Второго экрана «Выберите проект» быть не должно (G-22).
3. Откройте PROJECTS. В списке только ваши проекты.
4. Выберите `v12-hexagonal-facade-01`.
5. Ожидается: в течение нескольких секунд открывается **полное рабочее пространство DeGram**: чат, поле ввода, навигация слева, вверху полоса с проектом (`v12-hexagonal-facade-01 · UAT-A`). Только круговой граф без чата — это **fail**.

## 3. История чатов при переключении проектов (F-02, D-31)

1. В `v12-hexagonal-facade-01` посмотрите в боковую панель. Ожидается: список прежних чатов этого проекта, включая сегодняшние. Отметьте отдельно:
   - **3a**: список показывает старые чаты;
   - **3b**: старый чат открывается **со своими сообщениями**.
2. Откройте любой старый чат. Ожидается: видны его прежние вопросы и ответы, а не пустой чат.
3. Начните новый чат и отправьте короткое сообщение, например `маркер v12 шаг 3`. Дождитесь ответа.
4. Переключитесь на `degram-uat-b` через выбор проекта в полосе сверху (или через PROJECTS).
5. Ожидается: в списке **только** чаты `degram-uat-b`. Чата «маркер v12» и других чатов v12 здесь **нет**.
6. Откройте старый чат B. Ожидается: сообщения видны.
7. Вернитесь в `v12-hexagonal-facade-01`.
8. Ожидается: в списке снова чаты v12, включая «маркер v12 шаг 3». Откройте его: виден ваш вопрос и ответ модели.

## 4. Три проекта подряд (G-18)

1. Последовательно откройте `v12-hexagonal-facade-01` → `degram-uat-b` → `degram-uat-c` → `v12-hexagonal-facade-01`.
2. Ожидается: каждый проект открывается, окно **не** возвращается на стартовый экран, `degram-uat-c` открывается как третий.
3. В каждом проекте отправьте одно короткое сообщение. Ответ должен прийти из активного проекта, без текста провайдера или модели.
4. Если проект не открылся, должно появиться «Не удалось запустить агента для проекта …» с кнопкой «Повторить». Тихий возврат к выбору проекта — **fail**.

## 5. Отзыв доступа к проекту (G-20, F-01 после отзыва)

1. Откройте в DeGram `degram-uat-c`.
2. В браузере под администратором удалите вашего пользователя из участников `degram-uat-c`.
3. Вернитесь в окно DeGram: щёлкните по нему, чтобы оно получило фокус. Фокус запускает проверку доступа, иначе она пройдёт по таймеру.
4. Ожидается:
   - окно возвращается на стартовый экран;
   - уведомление «У вас больше нет доступа к degram-uat-c. Его данные и локальная история чата удалены с этого компьютера.» **остаётся на экране**, пока вы не нажмёте «×»;
   - под уведомлением снова Web UI с PROJECTS, а **не пустая белая область**;
   - в PROJECTS больше нет `degram-uat-c`.
5. Выберите в PROJECTS `v12-hexagonal-facade-01`. Ожидается: проект открывается как в шаге 2.
6. Верните себя в участники `degram-uat-c` (под администратором).

## 6. Отзыв токена сопряжения (G-21, D-35)

1. Откройте в DeGram `v12-hexagonal-facade-01`.
2. В браузере под вашим пользователем откройте вкладку Connectors и **отзовите** сопряжение DeGram.
3. В DeGram отправьте сообщение в чат или переключите проект.
4. Ожидается:
   - **нет** текста «Токен доступа DG истёк и обновляется. Повторите запрос.»;
   - окно на стартовом экране с уведомлением «Токен сопряжения отозван. Создайте новый на вкладке Connectors в DG (в браузере) и вставьте его ниже.» и полем для токена;
   - под ним Web UI с PROJECTS, а не пустая область.
5. Не вводя новый токен, выберите проект в PROJECTS. Ожидается: «Сначала вставьте токен сопряжения», курсор в поле токена, проект **не** открывается.
6. Полностью выйдите из DeGram (трей → выход) и запустите снова.
7. Ожидается: стартовый экран **снова просит токен**. Отозванный токен удалён с компьютера, поэтому сбрасывать его вручную не нужно.
8. Создайте на вкладке Connectors новое сопряжение, вставьте токен `dgp_…` и нажмите «Подключить». Ожидается: «Сопряжение сохранено. Токен используется при открытии проекта.»
9. Выберите `v12-hexagonal-facade-01`. Ожидается: проект открывается, а его прежние чаты видны и открываются (повтор шага 3 после сопряжения).

## 7. Выход и повторный вход (F-01 на пути входа)

1. Трей → «Выйти из DG» (или выход в окне) и подтвердите.
2. Ожидается: форма входа DG, никаких данных прежнего проекта на экране.
3. Войдите снова. Ожидается: стартовый экран как в шаге 2 (PROJECTS), **не** компактный граф.
4. Выберите проект. Ожидается: открывается полное рабочее пространство.

## 8. Текст о лимите запросов (G-24, по возможности)

Шаг выполняется, только если провайдер модели ответит ограничением (HTTP 429). Специально его не вызывайте.

- Ожидается текст: «Лимит запросов к модели исчерпан. Повторите после … или обратитесь к оператору DG.» либо «Лимит запросов к модели исчерпан. Повторите позже или уточните у оператора DG, когда лимит обновится.»
- Слов «для проекта» быть **не должно**.

Если лимит не сработал, отметьте шаг как «не проверено».
