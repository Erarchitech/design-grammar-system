<objective>
Owner decision D-39 (2026-10-11): DeGram access is issued by a DG admin or the project owner, per project member, on CONNECTORS; the key never leaves the server; the user only signs in to DG. Today any user self-issues a `dgp_` pairing and pastes it into DeGram (plan 17). DeGram's DG partition already holds the cookie session and already knows the cookie mint (`POST /auth/delegated-token`), so the new access path is a session exchange gated by an active grant; the pairing routes are retired.

Purpose: DGCL-01 (sign in once, no token handling) and DGCL-05 (access controlled and revocable by the project owner/admin).
Output: grant store and routes, session exchange, retired pairing routes, spec and tests; framework commit.
</objective>
