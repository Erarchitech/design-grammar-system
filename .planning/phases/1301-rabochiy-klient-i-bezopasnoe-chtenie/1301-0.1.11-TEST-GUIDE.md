## 1. Запуск со старым `active-profile.json` (F-03)

1. Убедитесь, что `active-profile.json` содержит `scope-…` (шаг 0, пункт 4), и запустите DeGram из меню «Пуск».
2. Ожидается: **нет** уведомления «Не удалось запустить приложение — DeGram scope profile …». Окно DeGram со страницей DG: сразу стартовый экран, если сеанс DG сохранился, иначе форма входа.
3. Закройте DeGram и откройте `active-profile.json` ещё раз. Ожидается: значение `"profile": "default"` (одноразовая очистка при первом запуске; остальные ключи, например `_migrated`, на месте).
4. Запустите DeGram снова и войдите участником. Уведомления об ошибке по-прежнему нет.
5. Откройте проект в PROJECTS и закройте DeGram. В `active-profile.json` по-прежнему `default`: открытие проекта больше не записывает `scope-…`.

## 2. Отказ без гранта сохраняет открытый проект (F-07, D-48)

1. В DeGram откройте `v12-hexagonal-facade-01` (грант выдан), дождитесь кнопки на кольце.
2. Выберите в PROJECTS `degram-uat-c`, у которого **нет** гранта.
3. Ожидается:
   - `v12-hexagonal-facade-01` **остаётся открытым**: его бэкенд не останавливается, чат продолжает работать;
   - вверху страницы DG уведомление «Доступ DeGram к проекту degram-uat-c ещё не выдан…», оно остаётся до «×»;
   - страница DG снова показывает `v12-hexagonal-facade-01` (кольцо возвращается на него), а не `degram-uat-c`;
   - **нет** текста «шлюз недоступен».
4. Отправьте сообщение в чате v12: ответ приходит.
5. Нажмите «×» на уведомлении: оно исчезает, проект остаётся открытым.
6. Если нет ни одного открытого проекта (Меню → стартовый экран) и выбран проект без гранта: стартовый экран с тем же уведомлением, окно не белое.

## 3. Список сеансов после переключений (F-04)

Нужен проект, где у участника есть хотя бы один сохранённый сеанс (в v12 у участника их два).

1. Откройте `v12-hexagonal-facade-01`. В боковой панели в истории видны ваши сеансы (не «Сеансов пока нет»). Если нет ни одного, отправьте сообщение `маркер 0.1.11 шаг 3`, дождитесь ответа.
2. **A → B → A.** Переключитесь на `degram-uat-b`: в истории только сеансы B (или пусто, если их нет), сеансов v12 здесь нет. Вернитесь в `v12-hexagonal-facade-01`. Ожидается: прежние сеансы на месте, в том числе `маркер 0.1.11 шаг 3`, с сообщениями при открытии.
3. **A → отказ → A.** Из v12 выберите проект без гранта (шаг 2). Ожидается, что список сеансов v12 не пропал. Откройте любой сеанс: сообщения видны.
4. **A → Меню → A.** Нажмите «Меню», затем снова выберите v12. Ожидается: список сеансов на месте.
5. Закройте DeGram, запустите и откройте v12 ещё раз (холодный старт): сеансы на месте.

Важно: старые 12 чатов владельца в списке участника не видны, это правильно (чаты привязаны к пользователю).

## 4. Одна сфера в центре кольца (F-05, D-47)

1. На стартовом экране выберите проект (например, `degram-uat-b`).
2. Ожидается, пока проект поднимается:
   - **одна** сфера, строго в центре кольца (не ниже центра);
   - **никакой надписи** «Подключение к DG» ни вверху окна, ни под сферой (надпись допустима только как подсказка скринридера, визуально её нет);
   - только одна анимация подключения, не две.
3. Когда проект готов, сфера исчезает, на кольце появляется кнопка новой сессии, чат сам не открывается.
4. Повторите при другом размере окна (развернуть и уменьшить): сфера остаётся в центре кольца.

## 5. DeGram «Коннекторы» как таблица (D-45)

1. В DeGram откройте «Коннекторы» из боковой панели (проект открыт, роль viewer или editor).
2. Ожидается одна таблица всех коннекторов проекта:
   - названия в первом столбце, видимых линий между строками и столбцами **нет**;
   - справа статус: «Вкл» с **зелёным** индикатором у активных, «Выкл» с **красным** у остальных;
   - в строке DeGram: «Доступен» при выданном гранте; «Запрос отправлен» при ожидающем запросе; иначе «Запросить доступ»;
   - в строках Grasshopper, Revit и других: «Доступен» + «Создать токен» (если у вас есть доступ), «Запросить доступ» или «Запрос отправлен».
3. Переключите тему и размер окна: цвета Вкл (зелёный) и Выкл (красный) читаются в обеих темах.
4. Под участником-viewer без доступа к Grasshopper нажмите «Запросить доступ» в его строке (примечание можно оставить пустым или короткое, до 200 символов). Ожидается: строка меняется на «Запрос отправлен». Повторное нажатие невозможно.
5. Попробуйте открыть запрос ещё раз с другого окна или после перезагрузки страницы: остаётся «Запрос отправлен», новый запрос не создаётся.

## 6. Владелец выдаёт доступ, токен показывается один раз (D-46)

1. В браузере под **владельцем/админом** откройте Connectors, карточку Grasshopper (то же для Revit), выберите проект. Ожидается блок «Pending requests» с запросом участника и кнопкой «Grant».
2. Нажмите «Grant». Запрос уходит из «Pending requests», в «Approved access» появляется доступ участника с кнопкой «Revoke access».
3. В DeGram у участника (при необходимости обновите страницу «Коннекторы» или выйдите и войдите): в строке Grasshopper «Доступен» и кнопка «Создать токен».
4. Нажмите «Создать токен». Ожидается: токен показан **один раз** с предупреждением; после закрытия панели повторно его не посмотреть.
5. Участник без одобрения (другой проект или другой коннектор) токен создать **не может**: кнопки «Создать токен» нет, прямой вызов даёт ответ «CONNECTOR_ACCESS_REQUIRED».
6. В Web UI у владельца нажмите «Revoke access». В DeGram строка снова «Запросить доступ».
7. Запрос на DeGram (строка DeGram): «Запросить доступ» → у владельца в карточке DeGram «Pending requests» → «Grant» → «Доступен» в таблице участника. После этого проект с выданным грантом открывается (как в 0.1.10).

## 7. Короткая регрессия шагов 0.1.10, которые прошли

1. **Стартовый экран:** сверху нет надписи «DEGRAM», нет поля токена, кольцо с Graph Viewer, Model Viewer, PROJECTS.
2. **Боковая панель:** ровно Новая сессия, Граф проекта, Валидатор, Коннекторы, Модели, Меню, ниже закреплённые чаты и история. Закрепление чата в v12 не видно в `degram-uat-b`.
3. **Навигация:** Граф проекта → Graph Viewer, Валидатор → Model Viewer, Меню → кольцо, Новая сессия (и Ctrl+N) → новый чат.
4. **Модели:** нижняя полоса показывает компанию, проект и статусы мостов (без «Выбрать документ»); на экране «Модели» закрепление документа (один на мост).
5. **Отзыв гранта** при открытом проекте: проект закрывается, стартовый экран с уведомлением, история не удаляется. Выдайте грант снова.
6. **Отзыв членства:** уведомление «У вас больше нет доступа к … Его данные и локальная история чата удалены с этого компьютера.», проекта нет в PROJECTS. Верните участника и грант.
7. **Переключение проектов** v12 → B → C → v12 (в каждом дождитесь готовности и отправьте сообщение): сообщите время начала и конца, я проверю `desktop.log` (нет перезапуска бэкенда ушедшего проекта).
8. **Выход и вход:** трей → «Выйти из DG», затем вход; проект открывается как обычно.
