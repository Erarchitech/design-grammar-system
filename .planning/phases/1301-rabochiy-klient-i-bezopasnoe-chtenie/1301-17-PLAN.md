<threat_model>
## Trust Boundaries
- Browser session (Connectors tab) -> data-service: creates and revokes pairings.
- DeGram main process -> data-service exchange: long-lived dgp_ in, short-lived dgd_ out.
- DeGram userData on disk: safeStorage ciphertext only.

## STRIDE Threat Register
| ID | Category | Threat | Mitigation |
|---|---|---|---|
| T-1301-17-01 | Spoofing | A stolen dgp_ used from another PC | Revocable in Connectors; user-bound, membership re-checked per exchange; last_exchange shown; exchange only on loopback-published data-service in the local profile |
| T-1301-17-02 | Elevation | dgp_ used as a connector or session credential | require_principal rejects dgp_ everywhere except the exchange (PAIRING_NOT_A_PRINCIPAL) |
| T-1301-17-03 | Information disclosure | Token in logs, renderer, agent or URL | Hash-only server store; safeStorage on the client; one IPC crossing; Bearer header only; tests grep logs |
| T-1301-17-04 | Repudiation | Who used DeGram | Relay provenance keeps username/company/project; pairing records last_exchange |
| T-1301-17-05 | Denial of service | Exchange brute force | 401 without detail; tokens are 256-bit token_urlsafe; same limits as the delegated mint |
</threat_model>
