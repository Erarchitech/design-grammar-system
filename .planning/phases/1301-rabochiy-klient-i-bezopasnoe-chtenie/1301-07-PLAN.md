<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN → pyRevit Routes :48884 | Default all-interface bind, no auth |
| local processes → pyRevit Routes | Any local process can call routes |
| DeGram agent → MCP stdio child | Tool calls from LLM-driven agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1301-07-01 | Elevation | execute_code route | critical | mitigate | Route not registered at all; exact-set test |
| T-1301-07-02 | Elevation | LAN exposure | high | mitigate | Startup refuses non-loopback host; MCP probe fail-closed (D-23) |
| T-1301-07-03 | Tampering | save/create/modify/delete/export | high | mitigate | Not registered on either layer |
| T-1301-07-04 | Tampering | wrong document read | medium | mitigate | Identity-pinned reads with IDENTITY_MISMATCH/DOCUMENT_NOT_OPEN |
| T-1301-07-05 | Denial of service | busy-spin / concurrent ExternalEvent race | medium | mitigate | 30 s client deadline → BUSY, serialized calls, no auto-retry |
| T-1301-07-06 | Info disclosure | other local processes read routes | low | accept | Loopback read-only data of the same user; documented residual risk |
</threat_model>
