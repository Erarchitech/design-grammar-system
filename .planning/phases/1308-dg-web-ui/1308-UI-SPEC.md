# Phase 1308 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Run mode:** AUTO, no user questions. Owner instruction 2026-10-12: «skip discussing, approve all recommendations». Every value below comes from `1308-CONTEXT.md` (D-01..D-49), `1308-RESEARCH.md`, `1301-D38-GLOSSARY.md` or the existing `ui-v2` design system. Where none answered, the recommended default matching the existing design system was chosen and is marked **[rec]** (recommendation adopted under that instruction).
>
> **Scope rule:** this phase adds NO new visual language, NO new primitive and NO new package. It reuses the 23 primitives in `ui-v2/src/components/` and the 6-file token split in `ui-v2/src/styles/tokens/`. Everything is monochrome; Signal Red keeps its single meaning (selection, failure, destructive).
>
> **Revision 1:** checker fixes: specific button labels (no bare Cancel/Allow/Remove), typography collapsed to 2 declared sizes plus the existing landing label, new-element spacing limited to 4/8/16/24 with 20px declared as an existing-token exception, focal points added, Members-list overflow resolved.

## Spacing Scale

Declared scale for ALL new elements and new gaps in this phase (multiples of 4): 4, 8, 16, 24. (32 / 48 / 64 are not needed.)

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`--spacing-4`) | Gap between landing label and its summary line; gap inside the EN/RU control; label-to-field gap; helper-text gap under a toggle title |
| sm | 8px (`--spacing-8`, `--element-gap`) | Gap between row controls (Select, Button), between member rows, between confirm buttons |
| md | 16px (`--spacing-16`) | Gap between blocks inside the new «Project settings» panel; badge inset from the top edge; EN/RU segment horizontal padding |
| lg | 24px (`--spacing-24`) | Badge inset from the right edge; gap between panels (Members → Project settings) on `ProjectsScreen` |
| xl | 32px | Not used by new elements |
| 2xl | 48px | Not used by new elements |
| 3xl | 64px | Not used by new elements |

Exceptions (existing tokens/primitives, untouched; none is part of the new scale):
- **Panel inner padding `var(--card-padding)` = 20px.** Justified: it is the existing `Panel` primitive padding shared by every panel in `ui-v2`; changing it would shift all screens. The new «Project settings» panel inherits it unchanged by using `Panel`.
- Existing Members panel 14px column gap and 10px row gap stay untouched (reuse as is). Nothing new copies them.
- Control heights are the existing primitive heights: `Select` 36px, `Button` md 36px / sm 28px, `Chip` 26px. The EN/RU control is 28px (= `Button size="sm"`). Desktop-pointer UI, so the 28px target is accepted as in the rest of `ui-v2`.
- Landing summary line gap is 4px (xs); its size is fixed 12px (see Typography), so no relative units.

## Typography

**Declared sizes for this phase: 2 (12px, 14px) plus the existing, unchanged fluid landing label.** Weights: 2 (400 regular, 500 medium). Line heights: 1.43 at 14px, 1.33 at 12px.

| Role | Size | Weight | Line Height | New elements mapped to it |
|------|------|--------|-------------|---------------------------|
| Body | 14px (`--text-body`) | 400 | 1.43 | Member username, Select value, checkbox row title, connector card body lines (status, sign-in count, access line, sign-in instruction), confirm text |
| Label / caption | 12px (`--text-caption`) | 500 for titles, status text and badges; 400 for helper, error, annotation and mono text | 1.33 | `Panel` title (uppercase, `--tracking-caption`, muted), `Badge`/status text, field labels above Selects, toggle helper text, inline error text (`ERR_STYLE`, set to 12px), visibility note, hosted caption, empty-state annotations, EN/RU control (Geist Mono 12px, uppercase, letter-spacing 0.14em), landing summary line (Geist Mono 12px, `text-transform: none`, `letter-spacing: 0.04em`, `font-variant-numeric: tabular-nums`, color `var(--text-muted)`, values `var(--text-primary)`) |
| Landing label (existing, unchanged) | `clamp(11px, 0.62vw, 24px)` Michroma uppercase | 400 | inherit | Landing region label first line, hero title; not restyled and not counted as new |

Rules:
- The landing summary is fixed 12px regardless of the label's fluid size; on narrow viewports it may exceed the label's size, which is accepted so the line stays legible.
- The earlier 11px and 13px steps are retired for new elements: `dg-annotation` lines are rendered at 12px (override the existing inline `fontSize: 11`), and field labels use a 12px caption above the control instead of the `Select label` prop (13px internal).
- Existing primitive internals are not restyled by this phase: `Button size="sm"` text stays 13px/500 and `Dialog` title 600; these are inherited from the primitives, not new declarations. (`Dialog` is not used here; confirms are inline.)
- Heading roles: none new. Existing hero/heading styles are unchanged.
- Russian note: RU strings run 20-40% longer than EN. No fixed-width containers for text; use `flex: 1` + `min-width: 0` + ellipsis only where stated.

Accent reserved for (explicit; nothing else):
1. Inline error messages (`ERR_STYLE`: role-change error, policy error, grant error). Landing summary failures show «—», never red.
2. `Button variant="destructive"`: «Revoke access» / «Отозвать доступ».
3. Existing `Badge variant="signal"` that marks `owner` in READ-ONLY role text elsewhere (unchanged); the new role `Select` itself is NOT red.
4. Existing selected-region highlight on the landing ring (unchanged).

Explicit non-uses:
- EN/RU control: active segment uses ink fill (`--color-ink-soft` background, `--text-inverse` text, same as `Badge variant="solid"`); inactive segment is transparent with `--text-muted`. Never Signal Red.
- Web UI connector status stays monochrome: `StatusDot` ink (`--status-pass`) when On, `--status-base` gray when Off, opacity 0.35 for never connected. «Вкл»/«Выкл» text next to the dot in `--text-primary`/`--text-muted`.
- DeGram-hosted connectors table only: «Вкл» uses `--status-on` (#2e9e5b light / #4cc77f dark) dot, «Выкл» keeps its existing red dot (unchanged from 1301-40; hosted exception documented in `colors.css`).
- Warning/info hues (`--color-warning`, `--color-info`) stay SHACL-only; not used here.
- Disabled controls: `opacity: 0.45`, `cursor: default` (the `Button` convention).

## Surface Contracts

### 1. Language badge (WEBUI-01, D-07, D-08)

- Component: `LanguageBadge.jsx` in `ui-v2/src/i18n/`, built from plain `<button>`s inside one rounded container; no new primitive export.
- Placement: `position: fixed; top: 16px; right: 24px; z-index` above the landing canvas and auth card, inside the landing layer only (hidden on Graph / Model / Projects / Connectors / Reasoner / LLM / API-docs screens, D-08). The existing theme toggle stays bottom-right; do not move it. Executor verifies no overlap with `.dgl-sys` / `.dgl-signout` readouts at 1280px and 1920px widths and in the host window.
- Form: segmented pill, height 28px, `border: 1px solid var(--color-hairline)`, `border-radius: var(--radius-full)`, background `var(--surface-input)`; two segments «EN» and «RU», each `padding: 0 16px`, Geist Mono 12px uppercase `letter-spacing: 0.14em`, gap between segments 4px.
- States: active segment = `--color-ink-soft` fill + `--text-inverse`; inactive = transparent + `--text-muted`; hover on inactive = `--text-primary`; `:focus-visible` = `box-shadow: var(--focus-ring)`; transition `var(--duration-fast) var(--ease-out)` on color/background only.
- Behaviour: click sets language immediately (no reload, no confirm); persists `localStorage["dgv2_lang"]` ∈ {en, ru}; sets `document.documentElement.lang`; sign-out keeps the key (`KEPT_KEYS`). Default EN when nothing stored (A5). Landing layout re-measures labels after a switch because label widths change.
- Host mode (`isDegramHost()`): language comes from `?lang=`; badge not rendered (D-07).
- Accessibility: container `role="group"` with `aria-label` = t("Language"); each segment `aria-pressed`, `lang="en"` / `lang="ru"` and `title` per the copy table; Left/Right arrows move focus between segments (native tab order is also kept).
- Visual weight: quietest element on the landing (see Focal Points).

### 2. Landing summaries (WEBUI-05, D-18..D-24)

- DOM: inside each existing `.dgl-region-label` element, after the label text, add `<span class="dgl-region-summary">` (display block). The label's `textAlign` already follows the ring side; the summary inherits it. The label stays `white-space: nowrap`, one click target, `cursor: pointer`, `:hover` opacity rule unchanged.
- CSS (add to `landing.css`): `.dgl-region-summary { display: block; margin-top: 4px; font: 400 12px/1.33 var(--font-mono); text-transform: none; letter-spacing: 0.04em; color: var(--text-muted); font-variant-numeric: tabular-nums; }` (fixed 12px, no `em`/`max()`). Values inside use `<span style="color: var(--text-primary)">`.
- Data timing: load once when the landing becomes active for a signed-in user; no polling; skeletons/spinners are not used (D-24).
- Overflow: longest realistic line is the RU Model Viewer line (~44 characters) and RU Graph Viewer line (~38); at 12px mono this is roughly 320-370px.
