<objective>
Persist an architect-accepted candidate as a standalone ParamState DesignState with full provenance, and close the read gap that would otherwise make that node invisible to the VALIDATION GRAPH component.

Purpose: SC2 requires the round-trip "stored as ParamState → visible in VALIDATION GRAPH reads → applied via PARAMETER REINSTATE". Two things stand in the way and neither was known at discuss time. First, no `:DesignState` writer exists anywhere in the repository — this plan builds the first one. Second, `Neo4jValidGraphRepository.RunsQuery` matches only `(:ValidationRun)` nodes and parses `run.statePayloadJson`; it never touches a `:DesignState` node, so a standalone ParamState is invisible to the canvas until an additive second read ships. 38-CONTEXT.md D-18's parenthetical claim that VALIDATION GRAPH reads "work unchanged" is the one part of that decision the codebase contradicts.

Output: `cg_paramstate_store.py` plus the accept route, and an additive standalone-DesignState read in the C# repository with test coverage.
</objective>

Its module docstring must state why it is a separate module from `cg_input_generation`: GHIN-04 and D-22 require the generation path to have no route to a write, and the import-boundary test in `test_cg_input_boundary.py` asserts that `cg_input_generation` does not import this module. Anyone merging the two breaks a requirement, not a style rule.

Define `class CandidateDomainViolation(ValueError)` carrying a `violations` list, and `class CandidateRequestInvalid(ValueError)`.

`compute_param_state_id(candidate) -> str` produces a deterministic `DS_`-prefixed id from the candidate's parameter set — a stable hash over the sorted `(parameterId, value)` pairs plus the `sourceRuleId`. Determinism is what makes the MERGE idempotent: accepting the same candidate twice must produce the same node, not a second one. Do not use the generation-time `candidateId`, which is per-request.

`accept_candidate(session, project, definition_id, rule_id, candidate) -> dict`:
1. **Re-read the live published `:Parameter` rows** for `definition_id` and `project` with a parameterized query, and rebuild `bound_params` through `cg_input_bindings.select_parameters`. Do not trust anything the client sent about domains.
2. Run `cg_input_sampler.validate_candidate(candidate["parameters"], bound_params)`. Any violation raises `CandidateDomainViolation` with the list — the route maps it to 422. This is the T-38-01 mitigation: the candidate travelled through a browser and back, and the published domains may have changed since generation.
3. Validate the provenance block carries all required keys; a missing `sourceRuleId`, `provider`, `model` or `generatedAt` raises `CandidateRequestInvalid`. A ParamState without provenance would silently defeat GHIN-03 at exactly the moment it becomes permanent.
4. Compute `StateId`, build the v2 `statePayloadJson` envelope satisfying the serializer invariants (`StateId`, ISO-8601 `CapturedAtUtc`), and write with a single parameterized MERGE:
   `MERGE (ds:DesignState {StateId: $stateId, project: $project})` then `SET` `kind = 'ParamState'`, `graph = 'ValidGraph'`, `statePayloadJson`, and every provenance property — `source`, `sourceRuleId`, `provider`, `model`, `confidence`, `definitionId`, `publishedAt`, `strategy`, `determinabilityClass`, `generatedAt`, `acceptedAt`. Include an `// op=ACCEPT_PARAM_STATE_CANDIDATE` trailing comment matching the publish module's convention.
5. Return `{project, stateId, kind: "ParamState", acceptedAt, parameterCount, provenance}`.

`fetch_generated_param_states(session, project, rule_id=None) -> list[dict]` is the GHIN-03 "queryable in the graph" read: a parameterized `MATCH (ds:DesignState {project: $project, kind: 'ParamState'}) WHERE ds.source = 'ai-generated'`, optionally filtered by `sourceRuleId`, returning `stateId`, `sourceRuleId`, `provider`, `model`, `generatedAt`, `acceptedAt`, `strategy`, `determinabilityClass`, ordered by `acceptedAt` descending. Plan 38-06's panel reads it and Task 4 asserts on it.

Every query parameterized; no string interpolation anywhere.
