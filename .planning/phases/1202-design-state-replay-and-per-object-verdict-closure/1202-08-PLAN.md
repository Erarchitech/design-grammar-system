`stateId` members, no `capturedAtUtc`/`objectRef` — see `fixtures/golden/seed.cypher:184`) cannot

Output: a seed for the replay project, a `--fixture`-selectable live path, a second independent
hash source in the C# leg, a refreshed retained report, and the ALGN12-11 checkbox reconciled.
</objective>

<critical_finding_that_shapes_this_plan>
**Wiring `--fixture` alone CANNOT produce `Agreement: agree`. Read this before Task 1.**

`report.compare_state_hashes` (`tools/de01/report.py:325-331`) computes:

- `not_applicable` when **fewer than two** legs reported a hash
- `agree` when 2+ legs reported and all hashes match
- `disagree` when 2+ legs reported and they differ

Today only `run_leg_replay` ever populates `LegResult.state_hash` (verified: the only assignment
is `tools/de01/legs.py:913`). `run_leg_data_service` and `run_leg_dg_reasoner` legitimately capture
no Design State (Open Question 2 — they must keep reporting typed absence), and `run_leg_csharp`
carries no hash because `DG.De01Harness` emits only an evidence envelope.

So even a perfectly seeded replay fixture yields **1 present leg -> still `not_applicable`**.

That is why Task 2 exists: the C# harness must become the second, genuinely independent hash
source. It already references `DG.Core`, where `DesignStateCanonicalProjection.ComputeHash`
(`DG/src/DG.Core/Serialization/DesignStateCanonicalProjection.cs:94`) lives. This turns the live
run into a real **cross-language** agreement demonstration (C# projection vs. Python projection),
which is precisely the claim the ROADMAP gate makes and which unit tests proved only in isolation.

**Do not shortcut this by making data-service or dg-reasoner report a hash they do not compute.**
That would fabricate agreement, violating this phase's governing rule that a declared
disagreement is acceptable and a silent or manufactured one is not.
</critical_finding_that_shapes_this_plan>
