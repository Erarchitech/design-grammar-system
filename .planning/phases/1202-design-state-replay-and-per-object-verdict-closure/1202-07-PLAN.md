<objective>
Extend DE-01 as this phase's exit evidence (D-16): per-object comparison plus canonical-state-hash
verification across the legs, run live once against the rebuilt stack.

Purpose: the ROADMAP gate is *"publish → query → replay reproduces the canonical state hash and
preserves mixed object verdicts"* — a cross-service claim that unit tests cannot substantiate.
`tools/de01/report.py:compare_legs` already does per-`(ruleId, objectId)` row comparison across all
four legs and is fully general, so the verdict dimension is largely satisfied once the replay leg's
rows flow through. What is genuinely new is a **second comparison dimension: the canonical state
hash**, which `compare_legs` has no concept of — it compares `EvidenceRow` entries and never a
scalar per leg.
Output: a state-hash dimension in the report, and one live four-leg run.

Open Question 2 resolved: the state-hash comparison is scoped to the legs that actually
produce or consume a Design State. `data-service` and `dg-reasoner` evaluate the rule fixture and
do not capture a Design State; forcing them to fabricate one would be exactly the silent
force-fitting the typed-absence idiom exists to prevent. They report `{"present": false}` with a
reason, and that is a correct outcome rather than a gap.

**Environment precondition, not a detail:** Docker Desktop was confirmed NOT running on the
research machine on 2026-09-21. Task 3 is gated on bringing it up, and on a `--no-cache` rebuild of
`data-service`, which has no source volume mount — a stale image silently runs pre-change code
(this bit Phase 38-06 and 1200-08).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `data-service` HTTP `/validation/view/{project}` → DE-01 replay leg | An untrusted or degraded response crosses into the comparison; a missing field must become typed absence, never a crash and never a silently-skipped leg |

| stored `statePayloadJson` → `compute_state_hash` in the view path | Malformed stored payload reaches the projection during a live HTTP request |
