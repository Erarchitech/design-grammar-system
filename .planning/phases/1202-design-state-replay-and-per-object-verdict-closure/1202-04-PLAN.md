<objective>
Build the per-object verdict read path in C# (ALGN12-10) and delete the fabricated status list.

Purpose: CONTEXT.md's Correction 2 and RESEARCH.md's Pitfall 4 both establish that this is a
**missing feature, not an index bug**. `RunsQuery` selects `runId, project, createdAt, rulesJson,
statePayloadJson` — neither `run.ValidStatus` nor `run.evidenceEnvelopeJson` is in the projection,
so no per-object data reaches C# at all. `Enumerable.Repeat(overallPass, objStateCount)` fabricates
a list from a run-level AND over *rules*. A grep for `ValidationEntity`/`HAS_ENTITY` across `DG/src`
returns zero hits. This plan builds the read path that did not exist, against the evidence envelope
that D-10 makes canonical.
Output: three additive types, one additive interface method, one new Cypher query, and the deletion
of the fabrication.

Discretion resolved here (D-13's name and signature):
`Task<PerObjectVerdictResult> GetPerObjectVerdictsAsync(ConnectionInfo connection, string runId,
CancellationToken cancellationToken = default)` on `IValidGraphRepository`, with the pure
deserialization+rollup split out as `internal static PerObjectVerdictResult
BuildPerObjectVerdicts(string? evidenceEnvelopeJson)` so it is unit-testable without a live Neo4j —
matching this repository's existing `TryParseDesignState` / `ParseRulesJson` testing seam.
</objective>

    - An envelope with zero rows yields `EnvelopePresent == true` and zero verdicts — "recorded but
